# МЭ-мост Репликации

<Row gap="20">
<BlockImage id="rep_ae2_bridge:rep_ae2_bridge" scale="8"></BlockImage>
</Row>

RepAE2Bridge — это компонент, который соединяет МЭ-систему AE2 с сетью материи Replication, обеспечивая бесшовную интеграцию между двумя системами.

## Возможности

Мост выступает переводчиком между двумя системами, позволяя данным материи Replication быть доступными внутри МЭ-системы AE2 и наоборот.

Это позволяет вам:
- Просматривать количества материи в сети Replication через терминалы AE2
- Запрашивать репликации через систему автокрафта AE2
- Настраивать приоритеты создания для оптимального управления ресурсами

## Установка

Чтобы установить мост, выполните следующие шаги:

1. Поставьте блок RepAE2Bridge в точке, которая может дотянуться до обеих сетей
2. Подключите МЭ-кабель AE2 к одной стороне блока
3. Подключите трубу материи Replication к другой стороне блока

## Настройка приоритета

Мост включает систему приоритетов, которая позволяет контролировать порядок, в котором обрабатываются запросы на создание. Это особенно полезно, когда у вас несколько мостов или вы хотите приоритизировать определённые типы предметов.

### Доступ к интерфейсу приоритета

1. **Нажмите ПКМ** по блоку моста, чтобы открыть интерфейс настройки приоритета
2. Введите значение приоритета в числовое поле
3. Значение может быть от −2 147 483 648 до +2 147 483 647
4. Более высокие значения приоритета обрабатываются первыми
5. Более низкие значения приоритета обрабатываются позже

### Рекомендации по приоритету

- **Положительные значения (1-1000)**: Высокий приоритет, обрабатываются раньше
- **Ноль (0)**: Приоритет по умолчанию, обычный порядок обработки
- **Отрицательные значения (-1 до -1000)**: Низкий приоритет, обрабатываются позже

### Случаи использования

- **Производственные мосты**: Установите высокий приоритет (100-500) для мостов, обрабатывающих критичные производственные предметы
- **Резервные мосты**: Установите низкий приоритет (-100 до -500) для мостов, предоставляющих резервную мощность создания
- **Экспериментальные предметы**: Установите очень низкий приоритет (-1000+) для тестового или экспериментального создания

## Оптимальная настройка

* Используйте только одну сеть Replication на мост
* По умолчанию мост может обрабатывать ~20 репликаторов одновременно
* Чтобы поддерживать большее количество репликаторов, используйте процессор создания с большим количеством Сопроцессоров изготовления
* Настраивайте приоритеты в соответствии с вашими производственными нуждами и доступностью ресурсов
