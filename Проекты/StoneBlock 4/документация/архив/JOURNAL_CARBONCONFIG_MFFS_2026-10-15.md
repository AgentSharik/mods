# Экран конфигов CarbonConfig: найден способ перевода — 15.10.2026

## Диагноз
Окно со скриншота (MFFS -> mffs-client) рисует CarbonConfig. Его хром переведён
(180/180 ключей gui.carbonconfig.*), но пункты чужих ModConfigSpec-конфигов
строились без локализации: ForgeLeaf.getName()/ForgeNode.getName() звали
IConfigNode.createLabel(имя) — «очеловечивание» ключа TOML, а описание —
дословный комментарий из кода мода. При этом у CarbonConfig есть второй вариант
createLabel(имя, ключ): при I18n.exists(ключ) берётся перевод.

## Способ (патч CarbonConfig-Neoforge-1.21.1-2.0.2.1.jar)
В ForgeLeaf.getName и ForgeNode.getName тело метода переписано байткодом вручную
(редактор классов /tmp/cu_build/classedit.py): строится ключ
<modid>.configuration.<путь через точку> (modid = ConfigPath.path()[0],
путь = ConfigValue.getPath() / список секций) и вызывается createLabel(имя, ключ).
Append-only constant pool (+22/+23 записи), ветвлений нет, стек пик 3 при
max_stack 4, сигнатуры не изменены, остальные байты JAR идентичны.
Безопасность: где ключа в ru_ru мода нет — прежнее «очеловеченное» имя.
Проверка статическая (дизассемблирование нового кода, сверка всех ссылок CP);
⚠️ запуска в игре не было. Если окно упадёт — откатить этот JAR из git.

Бонус: 126 ключей advancedperipherals.configuration.* из коммита 1948969 теперь
заработают и в CarbonConfig (подписи), а не только в экране NeoForge.
Описания пунктов в CarbonConfig по-прежнему берутся из комментариев классов —
для AP нужен отдельный патч комментариев (как здесь для MFFS).

## MFFS (mffs-5.4.44.jar)
- ru_ru: +36 ключей mffs.configuration.* (4 секции, 16 пунктов, 16 подсказок),
  итого 222 ключа, missing=0.
- MFFSConfig$Client/$Common: 16 английских комментариев заменены русскими прямо
  в классах — это описания пунктов в окне CarbonConfig.
Термины по готовому переводу мода: Генератор Фортрона, Матрица подавления,
силовое поле, Фортрон.

## Про «захардкоженные GUI» в целом
Метод Crash Utilities (точечная замена отображаемых строк в constant pool по
явной карте, командные литералы и ключи TOML не трогаются) — рабочий и теперь
применён уже дважды. Для конфиг-окон цепочка такая: подписи — патч CarbonConfig
+ ключи <modid>.configuration.* в моде; описания — патч комментариев мода.
