# KubeJS class filter: ошибка скрипта возврата шрифта

Дата: 2026-10-24. Статус: исправлено в v1.1.29; визуальная проверка Apotheosis всё ещё требуется.

## Скриншот пользователя

После установки v1.1.28 KubeJS показал экран `KubeJS client script errors`:

`ru_unicode_font.js#8 — Failed to load Java class 'java.io.File': Class is not allowed by class filter!`

Ошибка относится к файловому маркеру однократного восстановления шрифта, а не к Simply Swords или переводу Apotheosis.

## Исправление

Из `release/kubejs/client_scripts/ru_unicode_font.js` полностью удалены:

- `Java.loadClass('java.io.File')`;
- объект маркера и `getParentFile()`;
- `mkdirs()` и `createNewFile()`.

Вместо постоянного файлового маркера используется JavaScript-флаг `restoreDefaultFont` в памяти. При первом входе в мир за текущий запуск игры скрипт проверяет `forceUnicodeFont`, выключает его при необходимости и сохраняет настройки. При повторных входах в рамках того же запуска настройка не меняется. Единственный загружаемый Java-класс — `net.minecraft.client.Minecraft`, который уже использовался в v1.1.27 без ошибки class filter.

Имя скрипта сохранено, чтобы при установке перезаписать нерабочий вариант v1.1.28.

## Регрессионный контроль

Workflow теперь прямо запрещает в этом скрипте `java.io.File` и `createNewFile`, разрешает загрузку только `net.minecraft.client.Minecraft`, а также проверяет наличие флага в памяти и отсутствие `forceUnicode.set(true)`. Исправление JAR Simply Swords из v1.1.28 сохранено без изменений.

Синтаксис и логика дополнительно проверены Node.js с mock-объектами. Это не заменяет игровой тест: после установки нужно убедиться, что экран ошибки KubeJS исчез, обычный шрифт восстановлен, а русские подсказки уровней мира Apotheosis видны.
