# Crash Utilities 9.0.4 и расследование экрана конфигов Create — 15.10.2026

## Crash Utilities (crashutilities-9.0.4.jar)
Аудит: EN всего 4 ключа (только кейбинды), ru_ru нет, книг нет, зависимости — только
NeoForge. Весь интерфейс захардкожен строками в классах (CUScreen, MapGUI,
DataListLoader, GridRenderType и т.д.). Окно «Chunk Status» со скриншота — это он.
Upstream сверен: GitHub Darkere/CrashUtilities, коммит 8ac8a96 (mod_version=9.0.4),
en_us совпал с JAR (кроме CRLF).

Перевод (точечное исключение из правила «только ru_ru.json» — доказанно отображаемые
строки классов):
- assets/crashutilities/lang/ru_ru.json — 4/4 ключа.
- Замена строк в constant pool 29 классов по явной карте EN→RU (138 замен):
  GUI (подписи, тултипы карты чанков, состояния чанков, кнопки и меню действий,
  выпадающие списки, «Состояние чанка», «Пока ничего» и т.п.), сообщения чата команд
  /cu (включая справку help), предупреждения очистки предметов и дампа памяти,
  комментарии ServerConfig (подсказки конфиг-экранов) и два отображаемых значения
  по умолчанию (ITEMCLEAR... — действуют только для новых конфигов).
Проверка: missing=0, плейсхолдеры \u0001 и §-коды сохранены, классы после патча
парсятся, число CP-записей неизменно, изменены только 29 классов + добавлен ru_ru,
testzip=None. Запуска в игре не было.
НЕ тронуто сознательно: имена секций конфига («Item Clear», «Memory Checker»,
«Ftb Chunks» — это ключи TOML), командные литералы (/cu tp, ftbchunks unload_all,
title @a...), аргумент «Console», строки только для логов, имена потоков задач.
Термины: Chunk Ticket → «билет (чанка)», Tile Entity → «блок-сущность».

## Экран конфигов из Create — это Catnip, а не Configured и не Flywheel
Отдельного мода Configured в сборке нет (ConfiguredDefaults от Fuzs — другое).
Во вложенном flywheel-...jar GUI-классов ноль. Тёмное меню конфигов рисует Catnip:
классы net.createmod.catnip.config.ui.* лежат в ponder-...jar, вложенном в
create-1.21.1-6.0.10.jar. Список «других модов» — ConfigModListScreen, хлебные
крошки «modid > common > секция» — его формат.

Следствие для Advanced Peripherals: Catnip названия пунктов строит функцией
toHumanReadable(ключ TOML), в lang-файлы не смотрит; подсказка — дословный
комментарий из кода мода. Поэтому 126 ключей advancedperipherals.configuration.*
(коммит 1948969) в экране Catnip НЕ работают — они действуют только в родном
экране NeoForge (список модов → Config). В экране Catnip у AP переводимы лишь
комментарии-подсказки правкой классов; названия пунктов останутся «очеловеченными»
ключами TOML. Делать ли такой патч AP — на решение владельца сборки.
