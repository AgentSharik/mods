# Полный аудит всех 414 модов после двух крашей (2026-10-26)

По требованию пользователя: сплошная проверка каждого файла каждого мода — краш-риски и непереведённости.

## Что проверялось
1. Парсинг всех 99 917 .class файлов (магия, пул констант) — битых классов нет.
2. Перекрёстные ссылки внутри JAR: классы затенённых библиотек, на которые ссылается код, обязаны существовать в том же JAR (механизм краша Ars Nouveau). Срабатывания: Jade (тестовый ExamplePlugin), AE2WirelessTerminals и CompactMachines (API вынесены авторами в отдельные jar) — во всех трёх случаях состав байт-в-байт равен архиву пользователя, это норма upstream.
3. Валидность всех .json: «битые» файлы (16 модов) — все как в оригиналах (Gson в игре терпит комментарии), наших среди них нет.
4. Целостность: testzip по всем 414 — чисто; количество записей и байтовое сравнение с двумя базами оригиналов — потерь нет (только осознанное удаление фейкового lang Fallen Relics).
5. Перевод: паритет ключей по каждому файлу (единственный пропуск — служебный `_comment` Iron Furnaces), пустые значения, плейсхолдеры по всем 90 тыс. ключей, «голый %» в строках с аргументами.

## Исправлено по итогам (6 JAR, только ru_ru)
- Draconic Evolution: 4 пустых имени тех. уровней (Хаотичный/Драконий/Дракониевый/Виверновый — по терминологии самого мода).
- Iron's Spellbooks: пустое имя предмета scroll → «Свиток».
- Supplementaries: в подсказке пушки обе клавиши были %2$s → возвращён %1$s.
- Modular Routers: %d/%f приведены к %s как в оригинале (безопасный тип), единица mB исправлена с «мВ».
- Reliquified Twilight Forest: незаэкранированные % в строке с аргументами → %%.
- Mekanism: убран лишний %2$s, которого нет в оригинале.

Остальные срабатывания плейсхолдеров (110) прочитаны: стиль %s самого ProjectE, паттерны бочек Sophisticated, битый английский Iron's и Draconic — функционально корректны, не тронуты. 131 строка с «голым %» без аргументов безопасна (форматирование без аргументов не применяется) и повторяет оригиналы.
