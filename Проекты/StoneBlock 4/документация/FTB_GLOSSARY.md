# Глоссарий кластера FTB

Единые термины для модов семейства FTB (ftb-library, ftb-teams, ftb-chunks,
ftb-essentials, ftb-ultimine и остальных). Заведён при переводе ftb-teams
(13.10.2026); обязателен для всех последующих модов кластера.

| English | Русский | Комментарий |
|---|---|---|
| team | команда | общий термин FTB Teams |
| party (party team) | группа | тип команды из игроков; не «команда» |
| player team | команда игрока | персональная команда каждого игрока |
| server team | серверная команда | |
| member | участник | |
| officer | офицер | ранг |
| owner | владелец | |
| ally | союзник | rank и статус |
| ranks | ранги | enemy — враг, invited — приглашён |
| invite / invitation | пригласить / приглашение | |
| kick | исключить | |
| disband | распустить | |
| team property | свойство команды | Property %s — «Свойство %s» |
| team stage | этап команды | |
| (limited) lives | (ограниченные) жизни | механика limited lives |
| My Team | Моя команда | кнопка и заголовок интерфейса |

Стилевые правила кластера: существующие переводы FTB обращаются к игроку
на «Вы» — новые строки пишутся в том же стиле; повелительные формы кнопок
сохраняются («Выйти из группы»).
