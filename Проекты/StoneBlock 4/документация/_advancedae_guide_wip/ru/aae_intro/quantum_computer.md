# Квантовый компьютер

Квантовый компьютер — особый вид компьютера изготовления. Он способен выполнять неограниченное количество запросов
изготовления, пока у него достаточно хранилища изготовления.

## Ядро квантового компьютера

<BlockImage id="advanced_ae:quantum_core" p:powered="true" p:formed="true" scale="4"></BlockImage>

Ядро квантового компьютера — сердце Квантового компьютера. Само по себе оно имеет 256М хранилища изготовления и 8 потоков сопроцессора
. Это единственный блок, который может сам создать сформированный квантовый компьютер и дать все преимущества
квантового компьютера. Однако при использовании для создания мультиблока можно создать гораздо более мощный компьютер. При использовании как
отдельного компьютера энергия должна подаваться через стороны Вверх или Вниз, где находятся соединители.

## Хранилища квантового компьютера

<Row gap="20">
<BlockImage id="advanced_ae:quantum_storage_128" scale="4"></BlockImage>
<BlockImage id="advanced_ae:quantum_storage_256" scale="4"></BlockImage>
</Row>

Эти блоки расширяют хранилище изготовления ядра квантового компьютера. Они эффективно увеличивают количество одновременных задач,
которые способен выполнять квантовый компьютер. Есть два варианта, с ёмкостью 128М и 256М.

## Квантовый запутыватель данных

<BlockImage id="advanced_ae:data_entangler" scale="4"></BlockImage>

Запутыватели данных — особый блок, влияющий на все блоки хранилища, присутствующие в мультиблоке. Они позволяют блокам
хранилища хранить данные в нескольких измерениях, эффективно умножая их хранилище на 4. Только один из них можно разместить
в каждом мультиблоке квантового компьютера.

## Ускоритель квантового компьютера

<BlockImage id="advanced_ae:quantum_accelerator" scale="4"></BlockImage>

Ускорители квантового компьютера добавляют 8 сопроцессоров в мультиблок Квантового компьютера. Важно отметить, что все шаблоны
изготовления, выполняемые квантовым компьютером, способны разделять все сопроцессоры, поэтому, вероятно, хорошая идея инвестировать
в большое их количество.

## Многопоточник квантового компьютера

<BlockImage id="advanced_ae:quantum_multi_threader" scale="4"></BlockImage>

Подобно Запутывателям данных, многопоточники позволяют ускорителям выполнять дополнительные потоки в отдельных измерениях,
умножая их мощность сопроцессинга на 4. Только один из них можно разместить в каждом мультиблоке квантового компьютера.

## Мультиблок

Для создания мультиблочного квантового компьютера должны соблюдаться некоторые правила:
- Максимальный размер — 7x7x7 (внешние размеры);
- Внутри мультиблока не может быть пустых пространств. Их можно заполнить <ItemLink id="advanced_ae:quantum_unit" />
без дополнительных преимуществ;
- Ровно одно <ItemLink id="advanced_ae:quantum_core" />;
- Не более одного <ItemLink id="advanced_ae:data_entangler" />;
- Не более одного <ItemLink id="advanced_ae:quantum_multi_threader" />;
- Все блоки на внешнем слое должны быть <ItemLink id="advanced_ae:quantum_structure" />;
- Ни один блок внутри не может быть <ItemLink id="advanced_ae:quantum_structure" />.

## Настройки сервера

Несколько значений могут настраиваться конфигами сервера. Например:
- Максимальный размер мультиблока;
- Сопроцессоры в каждом Ускорителе квантового компьютера;
- Максимальное количество Многопоточников квантового компьютера;
- Значение умножения потоков Многопоточника;
- Максимальное количество Запутывателей данных;
- Значение умножения хранилища Запутывателя данных;

Лимиты для вашего экземпляра можно проверить с помощью подсказок предметов.
