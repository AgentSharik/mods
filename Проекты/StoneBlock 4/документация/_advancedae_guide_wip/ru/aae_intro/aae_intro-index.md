# Advanced AE!

Advanced AE сосредотачивается на улучшении пользовательского опыта при работе с МЭ-системой и расширении возможностей
систем финальной стадии. Этот мод позволяет улучшать поставщиков шаблонов способностью выталкивать предметы в конкретные стороны
целевых машин и создавать мультиблочные компьютеры, которые могут выполнять неограниченное количество изготовлений, разделяя
сопроцессоры, пока у них есть хранилище изготовления, плюс масса других улучшений качества жизни!
