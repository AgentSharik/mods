# МЭ шина импорта/экспорта

<GameScene zoom="8" background="transparent">
  <ImportStructure src="../structure/cable_import_export_bus.snbt"></ImportStructure>
</GameScene>

Шина импорта/экспорта — смесь <ItemLink id="ae2:import_bus" /> и <ItemLink id="ae2:export_bus" />.
Фильтр можно установить, чтобы настроить экспортируемые стаки. Всё, чего нет в фильтре, является допустимым стаком для импорта.
