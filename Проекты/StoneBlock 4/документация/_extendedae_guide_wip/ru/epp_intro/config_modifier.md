# Модификатор конфигурации

Модификатор конфигурации — инструмент для массового изменения инвентарей конфигурации.

<ItemImage id="extendedae:config_modifier" scale="4"></ItemImage>

Щёлкните по нему правой кнопкой, чтобы открыть его интерфейс.

## Использование

Модификатор конфигурации может быстро модифицировать инвентари конфигурации, например интерфейса, согласно его настройкам; например,
устанавливая настроенные количества предметов на максимальное значение или удаляя их все.

Вы можете щёлкнуть Модификатором конфигурации по целевому устройству (блоку или подчасти) в мире, чтобы модифицировать его конфигурацию.

## Настройки

У него две главных настройки: **режим модификации** и **величина модификации (X)**.

Вы можете щёлкнуть по кнопке, чтобы сменить режим.

![Интерфейс](../pic/cm.png)

- Прибавить/Вычесть/Умножить/Разделить: прибавить, вычесть, умножить или разделить настроенное количество на X.
- Максимум: установить настроенное количество на максимальное значение.
- Минимум: установить настроенное количество на минимальное значение.
- Установить: установить настроенное количество на X.
- Очистить: очистить все настроенные предметы.
