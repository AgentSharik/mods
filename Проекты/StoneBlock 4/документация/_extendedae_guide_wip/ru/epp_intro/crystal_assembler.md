# Кристальный сборщик

<Row>
<BlockImage id="extendedae:crystal_assembler" scale="8"></BlockImage>
</Row>

Эти расширенные устройства слишком сложны, чтобы сделать их на верстаке, поэтому для создания большинства из них вам понадобится Кристальный сборщик.

**Примечание: грань с экраном не может подключаться к сети.**

Он также может выполнять некоторые рецепты преобразования в мире, например преобразование флюиса.
