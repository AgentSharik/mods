# МЭ сверхразмерный интерфейс

<Row gap="20">
<BlockImage id="extendedae:oversize_interface" scale="8"></BlockImage>
<GameScene zoom="8" background="transparent">
  <ImportStructure src="../structure/cable_oversize_interface.snbt"></ImportStructure>
</GameScene>
</Row>

МЭ сверхразмерный интерфейс имеет то же количество слотов, что и <ItemLink id="extendedae:ex_interface" />, но может удерживать в 16 раз больше
предметов в каждом слоте (настраиваемо). Это значит, он может удерживать 1024 (64 x 16) предметов в каждом слоте.

Для определённых предметов из других модов можно настроить конкретный множитель.
