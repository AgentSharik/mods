# Модификатор шаблонов

Модификатор шаблонов — инструмент для массовых модификаций шаблонов.

<ItemImage id="extendedae:pattern_modifier" scale="4"></ItemImage>

Щёлкните по нему правой кнопкой, чтобы открыть его интерфейс.

## Режим умножения

Вы можете умножить или разделить количества входа и выхода шаблона обработки на коэффициент x, щёлкнув по соответствующей кнопке.

![МШ](../pic/pm.png)

Исходный шаблон:

![МШ1](../pic/pm1.png)

После ×10:

![МШ2](../pic/pm2.png)

Он также может очистить содержимое всех шаблонов и превратить их в пустые шаблоны нажатием кнопки Очистка.

### Примечания

 - Кнопка деления работает только тогда, когда соответствующее количество делится нацело. Например, кнопка ÷2 не будет работать, когда шаблон требует 3
 булыжника на входе, потому что 3 ÷ 2 — это 1,5.

 - Кнопка умножения имеет ограничение 999999. Она не может увеличить количество одного ингредиента сверх этого числа.

## Режим замены

Заменяет конкретный входной или выходной ингредиент в шаблоне другим предметом.

![МШ3](../pic/pm4.png)

Слот A — предмет, который нужно заменить, слот B — предмет-замена.

Например, следующая настройка заменит доски углём.

![МШ4](../pic/pm6.png)

![МШ5](../pic/pm5.png)

Нажмите кнопку Замена, чтобы выполнить замену.

![МШ6](../pic/pm7.png)

Изменяет режимы Замены и Замены жидкостей шаблона изготовления.
