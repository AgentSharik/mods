## Раскладка папок (с 13.10.2026)

Структура ветки приведена к виду «по назначению», и дальше работа ведётся по ней:

```
mods/
├── Проекты/                       ← переведённые моды
│   ├── StoneBlock 4/                  моды из сборки + документация
│   └── Отдельные моды/                моды вне сборок
├── Исходные моды для перевода/    ← оригиналы, не изменяются
└── README.md
```

| Папка | Что лежит | Как используется |
|---|---|---|
| `README.md` | описание проекта | в корне ветки, обновляется в корне |
| `Исходные моды для перевода/` | 61 исходный JAR | **источник**: отсюда берётся мод для перевода, файлы не изменяются |
| `Проекты/StoneBlock 4/` | готовые JAR модов из сборки | **результат**: сюда собирается каждый переведённый мод сборки |
| `Проекты/StoneBlock 4/документация/` | журналы, аудиты, глоссарии, черновики, картинки | всё рабочее, кроме самих JAR |
| `Проекты/Отдельные моды/` | готовые JAR модов вне сборок | сюда попадают моды не из StoneBlock 4: отдельные просьбы, моды из других сборок |

Папка называется `Проекты`, а не `ru_1.21.1`, потому что работа не привязана к одной сборке: внутри
каждая сборка и категория «Отдельные моды» — свой проект со своей папкой и своей документацией.
Название версии игры и загрузчика живёт в README, а не в имени папки.

Команды сборки теперь выглядят так:

```
python3 work/build_lang.py "Исходные моды для перевода/<мод>.jar" \
    "Проекты/StoneBlock 4/<мод>.jar" assets/<modid>/lang/ work/<мод>_ru.json
```

`work/` — служебная папка со скриптами и промежуточными файлами, в git не коммитится.

## 4. Farmer's Delight `FarmersDelight-1.21.1-1.3.4.jar` — 479 ключей, вычитка

**Аудит.** 2 441 запись, один lang-файл: `en_us` 479 ключей, `ru_ru` 480. Книг и гайдов нет.
В `ru_ru` на один ключ больше — `block.farmersdelight.pale_oak_cabinet`.

**Сверка источника.** Upstream — `vectorwing/FarmersDelight`, ветка `1.21`:

|---|---|
| `en_us` JAR ↔ `en_us` upstream | 479 / 479, **0 расхождений** |
| `ru_ru` JAR ↔ `ru_ru` upstream | 480 / 480, **0 расхождений** |

То есть в JAR лежит официальный перевод из репозитория мода, а не чья-то самодельная правка.
Работа свелась к вычитке: искать ошибки в тексте, который уже переведён и принят авторами.

**Что проверялось.** Помимо сплошного чтения всех 479 пар: совпадение с `en_us` (0 ключей
остались английскими), плейсхолдеры и `§`-коды (0 расхождений), латиница внутри русских слов,
двойные и краевые пробелы, сильное расхождение по числу слов (было 3, после правок — 0),
обращение («вы» в 4 строках, «ты» — только в одном заголовке достижения, исправлено).

**39 правок.** По типам:

- **фактические ошибки (9):** «спрут» вместо кальмара (`squid_ink_pasta`); «выше» вместо «ниже»
  в подсказке JEI; «лошади» вместо ездового животного (`mount`); «Обжареная» вместо
  «Обжаренная» (-нн- от глагола совершенного вида, 2 ключа); отсутствующая буква ё
  («Костер», «путем», «водоемах»); латинская «c» в слове «cвиней»; потерянная «нога»
  в описании ветчины («с ноги свиньи или хоглина»);
- **потерянный или искажённый смысл (8):** костёр «чтобы согреться ночью» вместо «чтобы
  приготовить еду»; пропущенные пшеница и рис в достижении про солому; «Выпечка нарезана»
  вместо «Еда нарезана»; «grilled to perfection» — «зажарен на гриле» вместо «до совершенства»;
  переписаны описания достижений про плодородную почву, ветчину, грибную колонию и застолье
  (в последнем была выдуманная вставка «Приготовьте свои миски!»);
- **пунктуация (3):** пропущенная запятая перед «чтобы», лишняя запятая перед «и»,
  «приступайте за готовку» → «приступайте к готовке»;
- **единообразие и стиль (19):** «паникула» → «метёлка» (ботанический термин, 3 ключа);
  «рубленая баранина» → «бараньи отбивные» по остальным ключам мода; «Блестящий салат»
  → «Сияющий салат» (согласовано со «светящимися ягодами»); «Предательство» → «Удар в спину»
  для зачарования Backstabbing; «Фермерские Изыски» → «Фермерские изыски» (капитализация
  названия мода выровнена в трёх местах); обращение на «ты» в заголовке достижения заменено
  на «вы»; «Пускать корни» → «Пустите корни»; «Красться для размещения тыквенного пирога»
  → «Размещение тыквенного пирога с Shift»; «похлёбки» → «рагу»; «Шпалера» → «Томат-великан»
  (передаёт игру слов `Tall-mato`).

**Вычитка и перекрёстная сверка.** Повторное чтение русского текста отдельно от английского
и сверка `en_us` ↔ `ru_ru` по парам: пропусков, вставок и расхождений по объёму нет,
латиница внутри русских слов не находится (два срабатывания — это `§l`, код форматирования).

**Спорные места:**

1. **«Рисовая метёлка» вместо «Рисовая паникула».** «Паникула» — не русское слово, в ботанике
   соцветие риса называется метёлкой. Заменено в трёх ключах, включая название тега.
   Возврат к «паникуле» — один откат, если сообщество привыкло к старому варианту.
2. **«Удар в спину» вместо «Предательство»** для зачарования Backstabbing. Прямое значение

3. **`Cabinet` → «Кладовая»** оставлено как есть: это устоявшийся перевод Farmer’s Delight,
   хотя буквально cabinet — «шкаф».
4. **Лишний ключ `block.farmersdelight.pale_oak_cabinet`** сохранён: его нет в `en_us` 1.3.4,
   но он есть в официальном `ru_ru` upstream — убирать оснований нет.

**Техпроверка скриптом** (`work/build_lang.py`): `en_us` 479, `ru_ru` 480 (1 ключ — из

|---|---:|---|

- ключи `_comment_modname_*` — это названия возможностей мода в списках конфигурации и справки;

  «Костёр», «Грибная похлёбка»;
- десятичные значения оставлены с точкой (от 0 до 1.0) — так они выглядят в файлах конфигурации,
  которые правит игрок (то же решение, что в Farmer’s Delight);
- команды, их аргументы и служебные имена вида `kit_name` не переводятся;
- имена собственные: `Serilum`, `Collective`, `Omega Mute` (внутри служебных сообщений),

русского порядка слов; набор спецификаторов сохранён полностью (проверено скриптом):

прочитана сюжетная линия `voidvanguards` (она читается как цельный рассказ: первая встреча
в космосе → радиопереговоры → база → финал → встреча с предводителем Пусторождённых).
Перекрёстная сверка `en_us` ↔ `ru_ru`: пропусков и вставок нет, двойные пробелы остались только
там, где они стоят в оригинале (6 ключей — отступы и выравнивание в сообщениях),
