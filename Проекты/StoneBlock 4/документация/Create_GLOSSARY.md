# Глоссарий Create (третья волна, кластер из 12 модов)

Составляется при вычитке Create (этап A третьей волны) и обязателен для всех аддонов
кластера: CreateDragonsPlus, create-enchantment-industry, create_connected, createaddition,
create-central-kitchen, create_hypertube, create-shimmer, createenchantablemachinery,
create_pattern_schematics, createenderstorage. База — официальный русский перевод Create
(принят как эталон терминов), спорные решения фиксируются здесь и в журнале волны.

## Правила кластера

- Технические подписи (`Shift`, `Ctrl`, `Alt`, `RPM`, единицы) не переводятся.
- Имя мода `Create` и производные названия в интерфейсе не переводятся.
- Шутки и каламбуры достижений сохраняются как шутки (официальный перевод это умеет:
  «Stress for Nerds» → «Так сильно?»), а не заменяются сухим пересказом.
