# Что такое Applied Energistics 2?

Applied Energistics 2 добавляет компоненты и механики для логистики и хранения. Огромную комнату,
забитую сундуками, можно заменить компактной МЭ-сетью — но это только начало.
Applied Energistics рассчитан на совместную работу с другими модами сборки и их автоматизацию. Систему можно настроить так,
чтобы она одним щелчком создавала все промежуточные компоненты (и конечный результат) сложной цепочки изготовления,
поддерживала заданные количества предметов в запасе, доделывая недостающее, или просто перемещала предметы по базе.
