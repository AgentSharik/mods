# МЭ накопитель

<GameScene zoom="8" background="transparent">
  <ImportStructure src="../assets/blocks/drive.snbt" />
</GameScene>

Накопитель — это [устройство](../ae2-mechanics/devices.md), в которое вы вставляете свои [ячейки хранения](storage_cells.md), чтобы использовать их для
[сетевого хранилища](../ae2-mechanics/import-export-storage.md). У него 10 слотов, каждый принимает ячейку.

Если по какой-то причине хотите, можно помещать и извлекать ячейки из его инвентаря любой предметной логистикой, например воронками или шинами AE2.

Его можно вращать <ItemLink id="certus_quartz_wrench" />.

## Светодиоды статуса ячеек

У ячеек в накопителе есть светодиод, показывающий их статус:

| Цвет  | Статус                                                                           |
| :----- | :------------------------------------------------------------------------------- |
| Зелёный  | Пуста                                                                            |
| Синий   | Есть некоторое содержимое                                                                |
| Оранжевый | [Типы](../ae2-mechanics/bytes-and-types.md) заполнены, новые типы добавить нельзя     |
| Красный    | [Байты](../ae2-mechanics/bytes-and-types.md) заполнены, больше предметов вставить нельзя |
| Чёрный  | Нет энергии или у накопителя нет [канала](../ae2-mechanics/channels.md)                 |

## Приоритет

Приоритеты задаются щелчком по гаечному ключу в правом верхнем углу интерфейса.
Предметы, входящие в сеть, сначала направляются в хранилище с наивысшим приоритетом как
в первое место назначения. В случае двух хранилищ или ячеек с одинаковым приоритетом,
если одно уже содержит этот предмет, оно будет предпочтительнее любого
другого. Любые [разделённые](cell_workbench.md) ячейки в той же группе приоритетов считаются уже содержащими предмет.
Предметы, удаляемые из хранилища, будут
удаляться из хранилища с наименьшим приоритетом. Эта система приоритетов означает, что при вставке и удалении предметов
из сетевого хранилища хранилища с высоким приоритетом будут заполняться, а с низким — опустошаться.
