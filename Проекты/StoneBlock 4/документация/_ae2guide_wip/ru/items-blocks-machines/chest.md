# МЭ сундук

<GameScene zoom="8" background="transparent">
<ImportStructure src="../assets/blocks/chest.snbt" />
</GameScene>

МЭ сундук работает как миниатюрная сеть с <ItemLink id="terminal" />, <ItemLink id="drive" /> и <ItemLink id="energy_acceptor" />.
Хотя его можно использовать как крошечную сеть хранения, его вместимость всего одной [ячейки хранения](../items-blocks-machines/storage_cells.md)
означает, что как таковая его полезность ограничена.

Вместо этого он полезен для взаимодействия конкретно с ячейкой хранения, установленной внутри него. Его встроенный терминал может видеть и обращаться только
к предметам в установленном накопителе, в то время как [устройства](../ae2-mechanics/devices.md) в общей сети могут обращаться к предметам в любом [сетевом хранилище](../ae2-mechanics/import-export-storage.md),
включая МЭ сундуки.

У него 2 разных интерфейса, и он направленный для транспортировки предметов. Взаимодействие с верхним терминалом открывает встроенный терминал. Предметы можно вставлять в
установленную ячейку хранения через эту сторону, но не извлекать. Взаимодействие с любой другой стороной открывает интерфейс со слотом для ячейки хранения
и настройками приоритета. Ячейку можно вставлять и извлекать предметной логистикой только через сторону со слотом ячейки.

Его можно вращать <ItemLink id="certus_quartz_wrench" />.

У него есть небольшой буфер энергии AE, поэтому если он не в сети с [энергохранилищем](../items-blocks-machines/energy_cells.md),
вставка или извлечение слишком большого количества предметов за раз может вызвать его отключение из-за нехватки энергии.

Терминал можно окрасить <ItemLink id="color_applicator" />.

## Настройки

У МЭ сундука такие же настройки, как у <ItemLink id="terminal" /> или <ItemLink id="crafting_terminal" />.
Однако он не поддерживает <ItemLink id="view_cell" />.

## Светодиоды статуса ячеек

У ячеек в сундуке есть светодиод, показывающий их статус:

| Цвет  | Статус                                                                           |
| :----- | :------------------------------------------------------------------------------- |
| Зелёный  | Пуста                                                                            |
| Синий   | Есть некоторое содержимое                                                                |
| Оранжевый | [Типы](../ae2-mechanics/bytes-and-types.md) заполнены, новые типы добавить нельзя     |
| Красный    | [Байты](../ae2-mechanics/bytes-and-types.md) заполнены, больше предметов вставить нельзя |
| Чёрный  | Нет энергии или у накопителя нет [канала](../ae2-mechanics/channels.md)                 |

## Приоритет

Приоритеты задаются щелчком по гаечному ключу в правом верхнем углу интерфейса слота ячейки.
Предметы, входящие в сеть, сначала направляются в хранилище с наивысшим приоритетом как
в первое место назначения. В случае двух хранилищ или ячеек с одинаковым приоритетом,
если одно уже содержит этот предмет, оно будет предпочтительнее любого
другого. Любые [разделённые](cell_workbench.md) ячейки в той же группе приоритетов считаются уже содержащими предмет.
Предметы, удаляемые из хранилища, будут
удаляться из хранилища с наименьшим приоритетом. Эта система приоритетов означает, что при вставке и удалении предметов
из сетевого хранилища хранилища с высоким приоритетом будут заполняться, а с низким — опустошаться.
