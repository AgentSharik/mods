# Пространственный якорь

<BlockImage id="spatial_anchor" p:powered="true" scale="8"/>

Сеть AE2 для работы любого из своих [устройств](../ae2-mechanics/devices.md) должна быть загружена в чанках, и если загружена только часть,
она может работать неправильно. Пространственный якорь решает эту проблему. Он принудительно загружает чанки, которые занимает его сеть.
Один кабель, пересекающий границу чанка, достаточен, чтобы загрузить этот новый чанк.

Он распространяет свою «загрузку» через [квантовые мосты](quantum_bridge.md), но не через измерения, поэтому если у вас
есть квантовый мост в Незер, нужен пространственный якорь в сети вашей базы и в сети в Незере.

По умолчанию он также включает случайные тики в своих загруженных чанках; это можно выключить в конфигурации AE2.

Его можно вращать <ItemLink id="certus_quartz_wrench" />, если по какой-то причине вы хотите это сделать.

## Настройки

*   Пространственный якорь даёт доступ к глобальной настройке отображения энергии в AE или E/FE.
*   Можно отобразить внутриигровую голограмму, показывающую загружаемые чанки.

## Энергия

Пространственный якорь использует [энергию](../ae2-mechanics/energy.md) по этой формуле:

e = 80 + (x\*(x+1))/2

где x — число загружаемых чанков
