# Ячейка просмотра

<ItemImage id="view_cell" scale="2" />

Ячейки просмотра используются для фильтрации отображения [терминалов](terminals.md). Вы разделяете их в <ItemLink id="cell_workbench" />.

Например, вы хотите, чтобы терминал показывал только подборку каменных строительных материалов. Разделите ячейку просмотра на эти
материалы и поместите её в терминал, и будут показаны только эти предметы.

Ячейки просмотра складываются: если есть ячейка просмотра для дубовых досок и ячейка для булыжника, установка обеих покажет
и доски, и булыжник.
