# Кристальный резонирующий генератор

<BlockImage id="crystal_resonance_generator" scale="8" />

Это устройство генерирует энергию для вашей МЭ-сети без потребности в топливе. Из-за вибраций кристалла, которые генерирует это устройство, в каждой сети можно использовать только одно. Эти вибрации проходят даже сквозь <ItemLink id="quartz_fiber" />.

**Темп генерации:** <ae2:ConfigValue name="crystalResonanceGeneratorRate"/> AE/тик
