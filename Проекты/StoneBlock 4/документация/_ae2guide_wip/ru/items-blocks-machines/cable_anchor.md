# Кабельный якорь

<GameScene zoom="6" background="transparent">
  <ImportStructure src="../assets/assemblies/cable_anchor.snbt" />
  <IsometricCamera yaw="195" pitch="30" />
</GameScene>

Небольшие декоративные шипы на кабелях, которые можно использовать, чтобы не давать кабелям соединяться, делать лестницы из кабелей или чтобы кабель выглядел
подключённым к окружающим его стенам. Также используются для создания <ItemLink id="facade" />.

Кабельные якоря не дают образовываться соединениям на той стороне, где они установлены.

По ним можно карабкаться как по лестнице.
