# Руководство

<ItemImage id="guide" scale="8" />

### Это руководство, которое вы сейчас читаете, для всех ваших потребностей в направлении по AE2.

* Используйте боковую панель слева, чтобы найти оглавление
* На многих страницах есть интерактивные сцены. Если рядом со сценой есть кнопки ![Плюс](../assets/diagrams/plus.png)
  и ![Минус](../assets/diagrams/minus.png) (масштаб), вы можете вращать и перемещать камеру.
  Зажатая левая кнопка мыши и перетаскивание — вращение, правая — перемещение.
