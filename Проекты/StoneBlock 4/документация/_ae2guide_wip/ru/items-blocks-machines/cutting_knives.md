Ножи для резки используются для изготовления <ItemLink id="name_press" /> и <ItemLink id="cable_anchor" />.

Чтобы сделать именной пресс, щёлкните правой кнопкой по ножу для резки и вставьте слиток металла, затем введите имя, которое
хотите написать на пластине, и просто извлеките готовую пластину.
