# Модуль слияния полей

Модуль слияния полей можно поместить в матрицу слотов [](@mffs:projector), чтобы объединить два или более проецируемых поля.

Модуль удаляет блоки проецируемого поля, пересекающиеся с другим силовым полем. Несколько силовых полей с этим модулем плавно объединяются в одно.
