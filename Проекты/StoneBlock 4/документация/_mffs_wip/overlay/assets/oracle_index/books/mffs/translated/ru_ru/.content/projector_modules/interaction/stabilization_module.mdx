# Модуль стабилизации

Модуль стабилизации можно использовать в [](@mffs:projector), чтобы превратить силовое поле в твёрдую конструкцию. Вместо энергетического барьера, исчезающего при выключении, проектор заменяет поле настоящими блоками, предоставленными игроком.

Так модуль стабилизации позволяет создать точную материальную копию структуры силового поля, которая останется и после отключения проектора. Прочность конструкции будет зависеть от прочности использованных блоков. Если проектор получает достаточно энергии и рядом есть блоки для замены, он будет восстанавливать разрушенную конструкцию.

Для стабилизации (переноса в материальную форму) требуется больше Фортрона, а сам процесс медленнее обычного проецирования. Однако в сочетании с режимом [](@mffs:custom_mode) возможности проектора почти безграничны.

Например, можно создать конструкцию, которая будет автоматически ремонтироваться, если [Creeper](@creeper) попытается её взорвать. Установив в проектор несколько [Speed Modules](@mffs:speed_module), можно стабилизировать сразу несколько блоков.

## Использование

- Поставьте сундук рядом с проектором силового поля (с любой стороны) и убедитесь, что в нём есть блоки, необходимые для постройки поля.
- Поместите модуль стабилизации в матрицу слотов проектора. Настройте поле по своему желанию, а затем включите проектор.
- Проектор будет забирать блоки из соседних сундуков в порядке их расположения. Если в сундуке лежат блоки разных типов, то конструкция также будет состоять из разных блоков.

## Использование в пользовательском режиме

В отличие от других режимов проектора, предмет пользовательского режима хранит точное положение и тип каждого проанализированного им блока. Поэтому стабилизация в режиме [](@mffs:custom_mode) работает иначе.
Вместо того чтобы забирать блоки по порядку и размещать их в произвольных местах, проектор будет использовать только те типы блоков, которые соответствуют исходному шаблону.

Каждый блок размещается точно в том месте и в том виде, которые заданы шаблоном. Если у проектора закончатся блоки нужного типа, он приостановит работу, пока не получит недостающие блоки.
