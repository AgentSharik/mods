# Модуль разрушения

Модуль разрушения можно использовать в [](@mffs:projector), чтобы изменить воздействие силового поля на окружающую среду. Установка модуля разрушения в матрицу слотов проектора заставит созданное им поле разрушать мешающие ему блоки. Разрушенные блоки выпадают как предметы, которые можно подобрать.

<PrefabObtaining />

## Использование

Модуль разрушения совместим со всеми режимами проектора и может обратить действие [](mffs:stabilization_module).
Установив [Speed Modules](@mffs:speed_module), можно одновременно разрушать несколько блоков. Модуль также можно сочетать с [](@mffs:collection_module), чтобы автоматически собирать разрушенные блоки.
