# Модуль ёмкости

Модуль ёмкости можно устанавливать в слоты улучшений различных машин MFFS, чтобы увеличить их возможности по хранению []($fortron). Эффект зависит от машины, но чаще всего модуль увеличивает запас []($fortron), который может хранить устройство.
