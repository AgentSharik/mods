# Биометрический идентификатор

Биометрический идентификатор — одна из машин MFFS. Он использует биосигнатуры игроков, чтобы определять их права при взаимодействии с силовыми полями и машинами MFFS.

Например, он может разрешить игроку проходить сквозь активное силовое поле или защитить его от воздействия [](@mffs:interdiction_matrix).

## Использование

Чтобы настроить биометрический идентификатор на распознавание игрока, откройте его интерфейс и поместите [](@mffs:id_card) в верхний левый слот предметов «Права». Если [](@mffs:id_card) пуста и ещё никому не назначена, держа её в руке, нажмите ПКМ, удерживая shift, чтобы назначить карту себе. Чтобы назначить карту другому игроку, нажмите ПКМ по нему, удерживая shift.

Затем включите нужные права игрока кнопками в правой части интерфейса. Каждая кнопка задаёт одно из следующих разрешений:

- **Проход**: игрок может крадучись проходить сквозь силовые поля;
- **Размещение блоков**: игрок может ставить и ломать блоки в области, защищённой матрицей подавления;
- **Взаимодействие с блоками**: игрок может открывать интерфейсы блоков и других объектов в зоне действия матрицы;
- **Настройка безопасности**: игрок может настраивать биометрический идентификатор и менять права пользователей;
- **Обход защиты**: игрок может игнорировать ограничения матрицы подавления;
- **Обход конфискации**: игрок не будет подвергаться конфискации предметов матрицей подавления;
- **Дистанционное управление**: игрок может управлять машинами, связанными с идентификатором, с помощью пульта.

Назначив игроку права, переместите его карту в любой из девяти слотов в нижней части интерфейса. Чтобы назначить себя владельцем биометрического идентификатора, поместите свою [](@mffs:id_card) в слот «Мастер».

Владелец биометрического идентификатора автоматически получает все права. Включите идентификатор сигналом редстоуна или нажатием кнопки с факелом редстоуна в левом верхнем углу интерфейса. После активации идентификатор загорится и начнёт работать.

## Примечания

Проходя сквозь силовое поле, игрок должен красться, пока полностью не выйдет из барьера, иначе силовое поле убьёт его.

[Identification Cards](@mffs:id_card) нельзя извлечь из идентификатора, пока он активен.

При прохождении сквозь силовое поле можно временно получить эффект тошноты IV.

Игрок в творческом режиме всегда может проходить сквозь силовое поле.
