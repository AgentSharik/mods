# Модуль разряда

Установка модуля разряда в [](@mffs:projector) наделяет силовое поле электрическим зарядом. При контакте с таким полем игрок или другое существо получает удар током и урон. Каждый дополнительный модуль разряда увеличивает урон по игроку или существу на половину сердца.
