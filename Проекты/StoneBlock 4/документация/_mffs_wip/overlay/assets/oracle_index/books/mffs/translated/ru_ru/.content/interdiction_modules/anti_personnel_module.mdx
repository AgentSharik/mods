# Модуль против игроков

Модуль против игроков — дополнительный модуль для [](@mffs:interdiction_matrix).

<PrefabObtaining />

## Эффект

С установленным модулем матрица автоматически обнаруживает игроков без разрешения, вошедших в зону действия, и почти мгновенно уничтожает их.

Мирные и враждебные мобы не пострадают.
