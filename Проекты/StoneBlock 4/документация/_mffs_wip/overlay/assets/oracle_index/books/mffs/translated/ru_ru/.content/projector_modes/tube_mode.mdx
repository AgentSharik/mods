# Режим трубы

По умолчанию режим трубы настраивает [Projector](@mffs:projector) на создание силового поля в форме квадратной трубы (четырёхгранной призмы) толщиной ровно в один блок. Трубчатое поле состоит из четырёх сплошных сторон, расположенных параллельно горизонтальной плоскости. Передняя и задняя стороны [Projector](@mffs:projector) образуют открытые грани трубы силового поля.

## Настройка поля

Поместите [](mffs:scale_module) в слот предметов, отмеченный стрелкой нужного направления, чтобы увеличить поле на 1 блок только в эту сторону.
Например, чтобы увеличить высоту силового поля на 1 блок, добавьте [](mffs:scale_module) в слот со стрелкой, направленной к верхнему левому или верхнему правому углу интерфейса.
