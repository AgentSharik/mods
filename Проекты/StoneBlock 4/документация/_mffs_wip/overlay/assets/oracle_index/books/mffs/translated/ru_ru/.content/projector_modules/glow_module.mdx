# Модуль свечения

Модуль свечения можно использовать в [](@mffs:projector), чтобы осветить пространство вокруг поля.

Установка модулей свечения в проектор заставляет силовое поле излучать свет. С каждым дополнительным модулем (до 64) яркость поля увеличивается — пока не сравняется с яркостью светокамня.
