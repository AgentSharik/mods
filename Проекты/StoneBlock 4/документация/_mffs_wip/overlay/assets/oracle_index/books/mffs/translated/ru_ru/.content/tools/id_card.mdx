# Идентификационная карта

Идентификационная карта MFFS используется вместе с [](@mffs:biometric_identifier), чтобы назначать игрокам права доступа.

<PrefabObtaining />

## Использование

Перед использованием идентификационную карту нужно назначить игроку. Держа карту в руке, нажмите ПКМ, удерживая shift, чтобы назначить её себе. Чтобы назначить карту другому игроку, нажмите ПКМ по нему, удерживая shift. Активируйте карту ещё раз, чтобы очистить сохранённые данные о владельце.
