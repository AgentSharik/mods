# Режим куба

По умолчанию режим куба настраивает [Projector](mffs:projector) на создание силового поля в форме куба толщиной ровно в один блок.

Каждый [](@mffs:scale_module) увеличивает размер силового поля на 1 блок во всех направлениях.

<PrefabObtaining />

## Настройка поля

Предмет режима куба также позволяет создавать силовые поля в форме прямоугольного параллелепипеда. Поместите [](@mffs:scale_module) в слот предметов, отмеченный стрелкой нужного направления, чтобы увеличить поле на 1 блок только в эту сторону.

Например, чтобы увеличить высоту силового поля на 1 блок, добавьте [](@mffs:scale_module) в слот со стрелкой, направленной к верхнему левому или верхнему правому углу интерфейса.
