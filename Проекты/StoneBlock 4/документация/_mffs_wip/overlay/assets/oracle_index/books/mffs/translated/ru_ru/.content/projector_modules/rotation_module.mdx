# Модуль вращения

Модули вращения можно поместить в слоты поля [](@mffs:projector), чтобы поворачивать проецируемое поле.

Силовое поле можно поворачивать вокруг осей X, Y и Z. Для этого поместите модуль вращения в соответствующий слот:

- ВОСТОК, ЗАПАД — задают рыскание;
- ВВЕРХ, ВНИЗ — задают тангаж;
- ЮГ, СЕВЕР — задают крен.
