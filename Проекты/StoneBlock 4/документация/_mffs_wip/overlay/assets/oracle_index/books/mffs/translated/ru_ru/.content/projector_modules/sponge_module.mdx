# Модуль губки

Модуль губки в [](@mffs:projector) постоянно обнаруживает и удаляет жидкости, находящиеся внутри силового поля. Установив [Speed Modules](@mffs:speed_module), можно увеличить скорость удаления жидкости. Для удаления бесконечных источников, например [Water](@mffs:water), может потребоваться более высокая скорость.
