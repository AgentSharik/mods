# Модуль смещения

Модули смещения можно помещать в слоты поля [](@mffs:projector), чтобы сдвигать положение проецируемого поля.

Поле можно сдвинуть в каждом направлении: поместите модуль смещения в соответствующий слот поля. Каждый модуль перемещает поле на 1 блок.
