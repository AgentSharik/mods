# Модуль блокировки доступа

Модуль блокировки доступа — дополнительный модуль для [](@mffs:interdiction_matrix). С его помощью матрица может ограничить доступ к интерфейсам блоков и машин: игроки не смогут открыть их, нажав ПКМ.

<PrefabObtaining />

## Эффект

Если игрок без доступа нажмёт ПКМ по блоку или машине в зоне действия матрицы подавления с установленным модулем блокировки доступа, он не сможет открыть интерфейс. За пределами зоны действия блоками и машинами можно пользоваться как обычно.
