# Добыча ресурсов

Первый шаг к созданию силовых полей — добыча основных ресурсов.

Компоненты MFFS в основном изготавливаются из [Steel Ingots](@mffs:steel_ingot); для этого нужно выполнить два простых шага. Сначала создайте [](@mffs:steel_compound) на верстаке, а затем переплавьте его в слитки.

Стальной слиток — один из самых распространённых компонентов MFFS. Он используется для создания основных компонентов, таких как [](@mffs:focus_matrix) или пустая карта, а также оборудования для силовых полей.
