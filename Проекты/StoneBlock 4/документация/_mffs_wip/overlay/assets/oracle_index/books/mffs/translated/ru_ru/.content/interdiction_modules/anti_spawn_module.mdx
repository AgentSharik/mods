# Модуль блокировки появления

Модуль блокировки появления — дополнительный модуль для [](@mffs:interdiction_matrix).

<PrefabObtaining />

## Эффект

С установленным модулем матрица не позволяет враждебным и мирным существам появляться в зоне действия.

Если у игрока есть яйцо призыва, он сможет призвать существо внутрь защищённой области, стоя прямо за границей зоны действия матрицы.
