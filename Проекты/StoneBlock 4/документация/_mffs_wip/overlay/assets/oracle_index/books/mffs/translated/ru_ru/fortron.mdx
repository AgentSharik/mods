# Фортрон

Фортрон — это вид энергии, используемый в качестве источника питания для машин MFFS. Сначала его производит и накапливает [](@mffs:coercion_deriver), а затем он передаётся другим машинам с помощью [](@mffs:fortron_capacitor).

Ещё один источник энергии Фортрона — Карта бесконечной энергии, доступная только в творческом режиме. Её можно поместить прямо в [](@mffs:fortron_capacitor) (в крайний левый слот для предметов), чтобы получить бесконечный запас Фортрона.

Фортрон также может находиться в жидком состоянии. Его можно выкачать прямо из [Capacitor](@mffs:fortron_capacitor) и перемещать так же, как [Water](@water) или [Lava](@lava).
