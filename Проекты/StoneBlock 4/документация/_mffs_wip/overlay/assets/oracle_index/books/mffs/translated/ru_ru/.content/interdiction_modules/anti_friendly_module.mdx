# Модуль против мирных мобов

Модуль против мирных мобов — дополнительный модуль для [](@mffs:interdiction_matrix).

<PrefabObtaining />

## Эффект

С установленным модулем матрица автоматически обнаруживает мирных существ, например овец, коров и жителей, попавших в зону сканирования, и почти мгновенно уничтожает их. Игроки и враждебные мобы не пострадают.
