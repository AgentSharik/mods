# Модуль против враждебных мобов

Модуль против враждебных мобов — дополнительный модуль для [](@mffs:interdiction_matrix).

<PrefabObtaining />

## Эффект

С установленным модулем матрица автоматически обнаруживает враждебных мобов, попавших в зону сканирования, и почти мгновенно уничтожает их.

Игроки и мирные существа, например жители и животные, не пострадают.
