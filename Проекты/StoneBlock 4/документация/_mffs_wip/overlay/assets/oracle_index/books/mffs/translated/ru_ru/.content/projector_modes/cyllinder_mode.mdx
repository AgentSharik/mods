# Режим цилиндра

По умолчанию режим цилиндра настраивает [Projector](@mffs:projector) на создание цилиндрического силового поля толщиной ровно в один блок. Каждый [](mffs:scale_module) увеличивает размер поля на 1 блок в выбранном направлении.

<PrefabObtaining />

## Настройка поля

Поместите [](mffs:scale_module) в слот предметов, отмеченный стрелкой нужного направления, чтобы увеличить поле на 1 блок только в эту сторону.
Например, чтобы увеличить высоту силового поля на 1 блок, добавьте модуль масштабирования в слот со стрелкой, направленной к верхнему левому или верхнему правому углу интерфейса.
