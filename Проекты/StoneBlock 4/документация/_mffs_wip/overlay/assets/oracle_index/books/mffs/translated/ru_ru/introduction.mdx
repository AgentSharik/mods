# Введение

Modular Force Field Systems (MFFS) — мод, добавляющий в Minecraft силовые поля, высокотехнологичные машины и средства защиты.

Надоели ядерные взрывы, разрушающие ваш дом, или хотите не пускать посторонних на секретную базу? Не волнуйтесь, мы вас защитим!

Силовые поля можно использовать для самых разных целей, например:

- Чтобы не пускать нарушителей в дом
- Для строительства сооружений
- Для создания подводных баз и воздушных шлюзов
- Для уничтожения приближающихся мобов
- Для поимки врагов в ловушки
- Для защиты от баллистических ракет
- Для конфискации предметов у игроков

В MFFS также есть настройки, позволяющие отключить зависимость от электрической энергии, поэтому мод можно использовать в ванильном Minecraft или вместе с другими модами. Чаще всего MFFS используют в многопользовательских мирах, но он пригодится и в одиночной игре.
