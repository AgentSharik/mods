# Проектор силового поля

Проектор силового поля — одна из основных машин MFFS. Он использует энергию []($fortron), чтобы создавать в мире силовые поля разных форм и размеров.

<PrefabObtaining />

## Использование

Чтобы создать силовое поле, обеспечьте проектор силового поля энергией []($fortron), связав его с ближайшим [](@mffs:fortron_capacitor).

Это можно сделать одним из двух способов:

- Нажмите ПКМ по проектору и введите соответствующую частоту в его интерфейсе.
- Держа карту частоты [](@mffs:frequency_card) в руке, нажмите ПКМ по проектору, удерживая shift.

Выберите форму поля, создав один из предметов режимов проектора. Нажмите ПКМ по проектору и поместите предмет режима в центральный красный слот, окружённый стрелками, направленными наружу.

Создайте несколько предметов [](@mffs:scale_module) и поместите их в матрицу слотов слева в интерфейсе проектора. Каждый [](@mffs:scale_module) в матрице увеличивает радиус силового поля на один блок.

Число в нижней части интерфейса показывает, сколько []($fortron) нужно для поддержания поля заданных размера и формы. Подайте сигнал [Redstone](@minecraft:redstone), чтобы включить проектор.

После активации проектор силового поля сменит цвет с красного на синий и начнёт проецировать поле, если доступного Фортрона достаточно.

Чтобы проходить сквозь силовое поле, потребуется [](@mffs:biometric_identifier).

## Улучшения

Проектор силового поля можно улучшить различными модулями.

- [](@mffs:scale_module): изменяет форму проецируемого силового поля;
- [](@mffs:speed_module): ускоряет создание поля проектором;
- [](@mffs:capacity_module): увеличивает запас Фортрона, который может хранить проектор.
