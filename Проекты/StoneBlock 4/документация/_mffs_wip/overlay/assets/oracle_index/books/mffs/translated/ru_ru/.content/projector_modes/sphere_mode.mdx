# Режим сферы

По умолчанию режим сферы настраивает [Projector](@mffs:projector) на создание сферического силового поля толщиной ровно в один блок.

Каждый [](mffs:scale_module) увеличивает размер силового поля на 1 блок.

<PrefabObtaining />

## Настройка поля

Установка [Scale Modules](mffs:scale_module) в слоты предметов, отмеченные стрелками, дополнительно увеличивает радиус силового поля на 1 блок за каждый модуль.
