---
title: Справочник по Markdown и MDX
---

Oracle Index отрисовывает практическое подмножество синтаксиса ModdedMC Wiki. Одну и ту же страницу можно использовать и на сайте, и в игре, если её внутриигровое представление укладывается в описанные ниже возможности.

## Обычный Markdown

Поддерживаются:

- заголовки;
- абзацы и переносы строк;
- **полужирный**, *курсив* и `код в строке`;
- нумерованные и маркированные списки, в том числе вложенные;
- относительные ссылки, ссылки по идентификатору контента, по ссылке на страницу, на ванильные предметы и на сайты;
- блоки кода с необязательным указанием языка и имени файла;
- цитаты;
- таблицы в стиле GitHub;
- изображения с подписями alt и атрибутами размера.

Внутриигровой движок не выполняет произвольные HTML, JSX, JavaScript и CSS. Неподдерживаемые блоки HTML и пользовательские компоненты не выводятся текстом, а игнорируются.

## Ссылки

Обычные относительные ссылки раскрываются относительно текущей страницы. Oracle Index понимает и такие формы ссылок вики:

```md
[Relative page](../machines/generator)
[](@minecraft:diamond_pickaxe)
[](+custom_page_ref)
[]($getting_started)
[Website](https://example.com)
```

`@namespace:id` открывает страницу контента, проиндексированную для этого идентификатора реестра. `+ref` использует значение `ref` из frontmatter страницы контента. `$slug` указывает на страницу документации. Пустые подписи ссылок заменяются заголовком целевой страницы или, где применимо, переведённым названием ванильного предмета.

Ссылки на якоря заголовков в игре пока не поддерживаются. Завершающий блок атрибутов заголовка скрывается при выводе для совместимости, но идентификаторы и атрибуты вроде `{#details}` или `{clear}` не влияют на раскладку и не дают цели для перехода.

## Изображения и ресурсы

Поддерживаются изображения Markdown, обычные элементы `<img>` и псевдонимы `<Asset>`/`<ModAsset>`:

```md
![](@example:machine_layout)
![Machine layout](@example:machine_layout){center width=160}
![Small icon](@example:icon){item}
<img src="@example:machine_layout" width="160" />
<Asset location="example:machine_layout.png" width="50%" />
```

По умолчанию изображения выравниваются по центру. `{left}` включает выравнивание по левому краю. `{center}` центрирует явно. `{right}` принимается для совместимости, но Oracle Index не умеет обтекать изображение текстом, поэтому в игре оно всё равно окажется по центру. Атрибуты ширины и высоты задаются в пикселях экрана, проценты — от доступной ширины контента. Изображение не выходит за пределы этой ширины.

Атрибут `{item}` всегда выводится в размере 32×32 и предназначен для иконок в виде предметов. Идентификаторы предметов из реестра, например `@minecraft:diamond`, используют настоящую игровую модель предмета. У отдельного изображения Markdown с текстом alt этот текст показывается как подпись.

В вики схемы 1 ресурсы загружаются из `assets/<namespace>/` внутри каталога вики. Расширения файлов по умолчанию — `.png` для изображений и `.ogg` для звуков. В вики старого формата используется `.assets/<namespace>/`.

## Предупреждения и врезки

Предупреждения в стиле GitHub поддерживают `NOTE`, `TIP`, `IMPORTANT`, `WARNING` и `CAUTION`:

```md
> [!TIP] Optional custom title
> Helpful content.

> [!WARNING]+
> Expanded by default and collapsible.

> [!CAUTION]- At your own risk
> Collapsed by default and expandable.
```

Метка `+` делает предупреждение сворачиваемым и изначально развёрнутым. Метка `-` делает его сворачиваемым и изначально свёрнутым.

Эквивалентный компонент поддерживает варианты `note`/`info`, `tip`, `important`, `warning` и `caution`/`danger`:

```mdx
<Callout variant="warning" title="Back up first" collapsible>
    Callout content can contain supported Markdown.
</Callout>

<Callout variant="danger" collapsed>
    This starts collapsed.
</Callout>
```

`collapsible` — изначально развёрнут. `collapsed` подразумевает возможность свернуть и изначально закрыт. Встроенные названия вариантов переводит сам Oracle Index, а произвольные заголовки — это содержимое страницы, и они задаются в каждом переведённом MDX-файле.

## Блоки кода и вкладки

Блок кода может содержать язык и имя файла:

````md
```json recipe.json
{"type": "minecraft:crafting_shaped"}
```
````

Вкладки кода содержат непосредственные дочерние блоки кода. После языка укажите `!!tabs`, а затем видимый заголовок вкладки:

````mdx
<CodeTabs>
```js !!tabs main.js
console.log("Hello");
```

```css !!tabs styles.css
body { margin: 0; }
```
</CodeTabs>
````

Подсветка синтаксиса и отдельный моноширинный шрифт пока не реализованы. Язык — это лишь метаданные, а текст на каждой вкладке выводится обычным шрифтом Minecraft. Вложенные обёртки внутри `<CodeTabs>` не разбираются.

## Другие поддерживаемые компоненты

`CraftingRecipe` выводит один рецепт 3×3. Массив `slots` должен содержать ровно девять идентификаторов предметов или пустых строк. Компонент не обращается к менеджеру рецептов и не поддерживает рецепты других размеров.

```mdx
<CraftingRecipe
    slots={['', 'minecraft:stick', '', '', 'minecraft:stick', '', '', 'minecraft:diamond', '']}
    result="minecraft:diamond_shovel"
    count={1}
/>
```

`Audio` проигрывает звуковой файл `.ogg` через внутриигровую кнопку воспроизведения и остановки:

```mdx
<Audio controls src="example:sounds/notification.ogg" />
```

`VideoEmbed` создаёт кнопку, которая открывает видео на YouTube. Само видео Oracle Index не транслирует и внутрь игры не встраивает:

```mdx
<VideoEmbed id="Y_WnAEKoeA4" />
```

Для всплывающей подсказки используется запись `?[label](description)`:

```md
A pickaxe is required to ?[mine](break while also dropping an item) this block.
```

Метка и описание — обычный текст. Вложенное форматирование и закрывающие круглые скобки внутри описания не поддерживаются.

## Поведение перевода

В вики схемы 1 переведённые файлы повторяют пути исходных ниже `translated/<locale>/`. Например:

```text
docs/machines/generator.mdx
translated/de_de/docs/machines/generator.mdx
translated/de_de/docs/machines/_meta.json
```

В вики старого формата вместо этого используется `.translated/<locale>/`. Язык подбирается по точному коду активного языка Minecraft. Английские языки используют исходные ресурсы. Отсутствующие переведённые файлы заменяются исходной страницей или метаданными.

Заголовок страницы берётся из `title` во frontmatter переведённой страницы, либо из первого заголовка первого уровня, либо из переведённого названия предмета в игре. Поиск индексирует только текст на исходном языке, но открывает переведённые результаты и показывает заголовки с учётом языка.
