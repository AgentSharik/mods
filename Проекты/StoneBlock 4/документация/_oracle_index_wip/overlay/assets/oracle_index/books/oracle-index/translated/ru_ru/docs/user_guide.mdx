---
title: Руководство пользователя
---

Oracle Index — клиентский мод с документацией, который показывает прямо в игре материалы с сайта [moddedmc.wiki](https://moddedmc.wiki/).

Разработчики модов могут вкладывать свои вики прямо в мод, а Oracle Index отображает их в игре. Чтобы открыть экран Oracle Index, нажмите клавишу вики (по умолчанию [H]).
Никакой отдельной книги-предмета не нужно. При закрытии экрана запоминается, на чём вы остановились.

Документацию мода можно посмотреть, только если этот мод установлен и его разработчик добавил свою документацию с moddedmc.wiki в виде вики Oracle Index.

## Переключение между модами

Слева на экране находится панель навигации по выбранному моду. Чтобы переключиться на другой мод, нажмите на заголовок мода над панелью навигации.
Откроется раскрывающийся список, в котором можно выбрать, какой мод просматривать.

## Ссылки на предметы

Разработчики могут привязывать страницы вики к игровым предметам. Если для предмета есть страница, в его подсказке появится небольшая дополнительная метка.
Удерживайте клавишу [ALT], глядя на подсказку предмета, чтобы открыть соответствующую запись вики.

## Язык

Oracle Index автоматически использует переведённые материалы для вашего языка Minecraft, если они есть в вики. Переводиться может содержимое страниц, метаданные навигации, заголовки страниц, встроенные элементы управления, врезки и служебные сообщения.

В вики схемы 1 переведённые страницы повторяют путь исходной страницы в каталоге `translated/<locale>/`, в вики старого формата — в `.translated/<locale>/`. Если переведённой страницы или файла метаданных нет, Oracle Index берёт ресурс на исходном языке.

Поиск пока индексирует только текст страниц на исходном языке. При этом результаты открывают переведённую страницу, если она есть, а заголовки выводятся на активном языке.
