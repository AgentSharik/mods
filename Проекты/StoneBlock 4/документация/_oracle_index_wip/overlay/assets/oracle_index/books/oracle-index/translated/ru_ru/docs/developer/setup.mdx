Эта страница предназначена для разработчиков, которые хотят, чтобы их вики открывалась через мод Oracle Index.

## Настройка проекта

1. Создайте каталог вики и раскладку контента как обычно, по инструкциям moddedmc.wiki.
2. Убедитесь, что у вас есть файлы _meta.json с записями для **всего** контента. Oracle Index строит панель навигации по этим файлам.
3. Скопируйте всю вику в каталог ресурсов вашего мода. Это можно автоматизировать, см. раздел [автоматическая синхронизация через Gradle](../developer/gradle_task). Правильный путь: «resources/assets/oracle_index/books/your-mod-id/».
4. Oracle Index автоматически загрузит ресурсы вашего мода.

Итоговое дерево каталогов должно выглядеть так:

<center>
<ModAsset location="oracle-index:folder_layout" width={600} />
</center>

Горячей перезагрузки нет. Создавать содержимое вики удобно в живом предпросмотре на moddedmc.wiki, а в игре контент обновит перезагрузка ресурсов.

Ресурсы внутриигровой вики можно добавлять и через пакеты ресурсов (в том числе вложенные в моды). Пример настройки смотрите в репозитории Oritech.

### Совместимость с Markdown

Oracle Index поддерживает возможности Markdown и MDX, которые обычно нужны вики на ModdedMC: таблицы, предупреждения, изображения, вкладки кода, врезки, рецепты, аудио и ссылки на видео. Синтаксис и точные ограничения описаны в разделе [Справочник по Markdown и MDX](./markdown).

Это отдельный внутриигровой движок отрисовки, а не браузер. Произвольные HTML, JSX, JavaScript, CSS и пользовательские React-компоненты не выполняются. Неподдерживаемые блоки HTML игнорируются. Простой тег `<img>` поддерживается, а обёрточные теги `<center>`, `<div>` и `<span>` в их простом виде отбрасываются.

В вики схемы 1 файлы изображений и звуков лежат в `assets/<namespace>/` внутри каталога вики, в вики старого формата — в `.assets/<namespace>/`. Старый каталог `.assets/item/<namespace>/` не нужен: предмет из реестра отрисовывается своей игровой моделью.

У страниц контента с корректным `id` появляется игровая панель свойств. Размер стопки, прочность, информация о добыче, уровень света и подобные значения берутся из активных игровых реестров.

### Ссылки на предметы

Ещё одна возможность Oracle Index — привязывать к странице вики подходящие предметы. Для этого во frontmatter страницы добавляется параметр «related_items» с массивом игровых идентификаторов предметов. Выглядит это так:

```
---
title: Generators
icon: oritech:basic_generator_block
related_items: [oritech:basic_generator_block, oritech:bio_generator_block, oritech:lava_generator_block, oritech:fuel_generator_block, oritech:big_solar_panel_block]
---
Here would be your content.
```

Эти ссылки создаются автоматически для записей контентной вики.

### Своя книга и открытие экранов

По умолчанию в Oracle Index нет книги-справочника. Но в своём моде можно легко добавить предмет-книгу и открывать нужный экран при её использовании.
Открыть книгу можно и другими способами, например кнопкой в другом экране.

Вызовите на стороне клиента следующий код:

```java
// Oritech is the wiki name here.
// Entry resources always use the oracle_index namespace.
Identifier entry = Identifier.of("oracle_index", "books/oritech/docs/intro.mdx");
OracleClient.openScreen("oritech", entry, MinecraftClient.getInstance().currentScreen);
```
