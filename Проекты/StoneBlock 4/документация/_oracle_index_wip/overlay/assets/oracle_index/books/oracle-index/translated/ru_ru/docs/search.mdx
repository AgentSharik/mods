---
title: Поиск
---

В Oracle Index есть умный поиск. Открыть окно поиска можно сочетанием [CTRL + ORACLE_HOTKEY] либо отдельной горячей клавишей поиска (по умолчанию не назначена). При просмотре записи вики есть и небольшая иконка поиска.

<Callout variant="info">
    Поиск поддерживает математические вычисления и выражения!
</Callout>

При первом открытии экрана поиска может понадобиться несколько секунд, чтобы проиндексировать доступные страницы. Поиск полноценный семантический, на основе машинного обучения: не обязательно подбирать точные ключевые слова — можно вводить целые предложения, и будут показаны подходящие материалы, даже если слова не совпадают буквально. Выводятся все подходящие темы.

## Технические подробности

Внутри Oracle Index строит эмбеддинги для всех страниц, предварительно разбивая их на фрагменты. Небольшая модель предложений (all-MiniLm-L6-V2-q) создаёт эмбеддинги для каждого фрагмента и для поискового запроса. Векторы эмбеддингов хранятся в памяти, после чего вектор запроса сравнивается с эмбеддингами фрагментов вики, и пользователю выводятся N наиболее близких результатов.

Используется библиотека Langchain4j на основе фреймворка DJL. Размер модели эмбеддингов — около 15 МБ.

## Ограничения

Поиск индексирует текст страниц на исходном языке и пока не строит отдельный семантический индекс для переведённого текста. При выборе результата всё равно открывается переведённая страница, если она есть, а заголовки результатов выводятся на активном языке.

Из-за модели эмбеддингов и нативной среды исполнения файл мода с поддержкой поиска получается крупнее. Если в версии для вашей платформы этой среды нет, Oracle Index сообщает, что поиск недоступен, и указывает на кроссплатформенную версию. Обычный просмотр вики от семантического поиска не зависит.
