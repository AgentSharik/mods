---

В Oracle Index есть возможность закрывать контент, пока игрок его не откроет. Закрытые страницы показываются в зашифрованном виде и не попадают в поиск.
Если в каталоге закрыты все записи, скрывается весь каталог.

<Callout variant="warning">
    Разумеется, эта возможность работает только во внутриигровой вики, а не на сайте. Основная аудитория здесь — авторы сборок, которые не хотят раскрывать всё сразу.
</Callout>

Чтобы управлять разблокировкой, во frontmatter страницы нужен раздел *unlock*. Выглядит это так:

```
---
title: Ingame Mod View Setup
unlock: advancement:minecraft:oritech/pulverizer
---
"unlock" is always the same
"advancement" is the name of the progress validator
anything after the "advancement:" part is passed to the validator
```

# Валидаторы

Разработчики могут регистрировать свои валидаторы в **Oracle Progress API**. Подробности — в javadoc класса API.

Oracle Index не хранит сведения о том, какие записи уже открыты, а просто вызывает валидаторы по мере необходимости.

## Валидатор достижений

По умолчанию в мод входит только один валидатор — валидатор достижений. Он проверяет, выполнено ли указанное достижение, чтобы открыть страницу.
