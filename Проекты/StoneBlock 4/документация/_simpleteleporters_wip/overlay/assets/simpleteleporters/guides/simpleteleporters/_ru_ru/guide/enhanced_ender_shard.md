# Усиленный эндерский осколок

<Row>
<Column>

Усиленный эндерский осколок — улучшенная версия <ItemLink id="simpleteleporters:ender_shard" />, которая позволяет телепортироваться между измерениями.

<ItemImage id="simpleteleporters:enhanced_ender_shard" scale="4" />

</Column>
<Column>

## Рецепт улучшения

Улучшите эндерский осколок на **кузнечном столе**:
- **Основа**: эндерский осколок (привязанный или непривязанный)
- **Добавка**: осколок эха

Привязанная точка сохраняется при улучшении.

</Column>
</Row>

## Путешествия между измерениями

В отличие от обычных эндерских осколков, усиленный позволяет телепортироваться между измерениями:
- Привяжите осколок к точке в Незере, а затем телепортируйтесь туда из Верхнего мира
- Создавайте сети телепортеров между измерениями
- Работает при телепортации игрока с удержанием Shift и при активации редстоун-сигналом

## Как использовать

1. **Вариант А**: сначала привяжите эндерский осколок к точке назначения, затем улучшите его на кузнечном столе
2. **Вариант Б**: сначала улучшите непривязанный эндерский осколок, затем привяжите усиленный осколок к точке назначения

Оба способа работают: при улучшении на кузнечном столе данные о привязке сохраняются.

## Возможности

- **Телепортация между измерениями**: работает в любых измерениях
- **Зачарованное сияние**: усиленный осколок отличается характерным блеском от обычного
- **Совместимость**: усиленный осколок поддерживает все функции телепортера: активацию редстоун-сигналом, перемещение сущностей и другие
- **Привязка и имя**: при улучшении сохраняются точка назначения и имя предмета

## Советы

- Осколки эха можно найти в Древних городах биома «Глубокая тьма»
- Усиленный осколок можно использовать и для телепортации в пределах одного измерения
- Используйте его для самых важных маршрутов между измерениями
