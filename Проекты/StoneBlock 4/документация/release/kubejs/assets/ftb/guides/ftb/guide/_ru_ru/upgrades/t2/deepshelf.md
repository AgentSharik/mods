# <Color id="green">Улучшение "Глубинное зачарование"</Color>

<ItemImage id="apothic_enchanting:echoing_deepshelf" scale="3" />

<Color id="light_purple">"Глубинное зачарование"</Color> - это второстепенное улучшение для <Color id="gold">мирового двигателя</Color>.

Это улучшение полезно для тех, кто использует <Color id="gold">Ars Nouveau</Color> и хочет добавить большей мощи для своих заклинаний.

Это улучшение также позволяет создавать несколько зачарований, а также рецепты <Color id="gold">Duality</Color> из Iron's Jewelry.
