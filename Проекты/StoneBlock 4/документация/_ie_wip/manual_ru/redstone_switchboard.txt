Редстоуновый коммутатор
Осмысленные соединения
При работе с несколькими сетями редстоуновых проводов соединение отдельных цветов друг с другом может в конечном итоге потребовать много пространства.<br>
Редстоуновый коммутатор облегчает эту проблему, позволяя любым сигналам из одной сети передаваться в другую, при этом цвета свободно переназначаются по пути.<br>
Сигналы проходят только в одном направлении; слева -> справа, когда стоите перед коммутатором.<br>
Дополнительно, коммутатор оснащён аналоговыми инверторами для всех сигналов, позволяя отправлять в выходную сеть инверсию входного сигнала.<np>
Чтобы настроить коммутатор, используйте Отвёртку инженера, чтобы открыть интерфейс. Щёлкните по любому из входных гнезд, чтобы начать соединять кабель там, затем щёлкните по выходному гнезду, чтобы завершить соединение.<br>
При желании, включите или выключите красную кнопку «инвертировать» на любой из выходных панелей — хотя обратите внимание, что инверсия имеет эффект только если к этому выходу есть соединение.
