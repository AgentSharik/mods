Верстак инженера для крафта
Для различных проектов
Верстак инженера для крафта — это простое улучшение обычного Верстака. В дополнение к столешнице из обработанной древесины, он сохраняет ингредиенты внутри сетки крафта, когда он закрыт.
Стол также оснащён небольшим ящиком для хранения некоторых ваших компонентов для крафта.
