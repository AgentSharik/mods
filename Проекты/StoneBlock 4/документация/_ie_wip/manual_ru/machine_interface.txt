Интерфейс машины
Быстрый запрос сложных условий
<&recipe>С ростом сложности мультиблочной техники, отслеживание их нужд становится довольно сложным.<br>
Хотя <link;redstone_probe;сигналы компараторов> могут дать некоторое представление о количестве предметов внутри, только Интерфейс машины может предоставить более детальную оценку и отправлять сигналы редстоуна.<np>
При размещении против поверхности управления редстоуном мультиблока, открытие графического интерфейса позволит настраивать разнообразные условия, при которых выводить сигнал.<br>
Нажмите кнопку «Добавить условие», чтобы добавить новую строку. В этой строке первая кнопка служит для её повторного удаления, вторая — для настройки цвета сигнала, на который выводить.<np>
За этим следуют два раскрывающихся меню, одно для выбора типа проверки (такой как «Машина активна», «Ввод предметов», «Вывод жидкости») и одно для выбора условия.<br>
Большинство проверок поддерживают «Выход компаратора» для силы сигнала, которая масштабируется в зависимости от хранящихся предметов/жидкости/энергии. Также существуют различные из вариантов «истина» или «ложь», такие как «Заполнено на 75%» или «Пусто».<np>
Как только условие будет выполнено, Интерфейс машины выведет соответствующий сигнал на настроенном цветном канале на любой прикреплённый <link;redstone_wiring;Редстоуновый интерфейсный коннектор;bundled>.<br>
В дополнение к отправке, Интерфейс машины может также принимать сигнал редстоуна и выводить его на подключённую машину. Цвет сигнала для этого настраивается в правом нижнем углу графического интерфейса.<np>
Это позволяет использовать <link;logic_unit;Логический блок> для оценки сигналов, поступающих от машины, а затем отправить один обратно, чтобы включить или отключить её!
