Внешний нагреватель
Теперь вы готовите с потоком!
<&recipe>Внешний нагреватель генерирует тепло из Flux, которое он выводит в тепловые отверстия по бокам.<br>
Он не может производить восстанавливающие атмосферы, используемые в Доменных печах, древесный дым для консервирования пищи или температуры, необходимые для печей для обжига.<br>
При размещении рядом с обычной печью эта тепловая энергия обеспечит печи тепло без потребления топлива.<br>
Стороны нагревателя можно настроить Молотом инженера, присядьте, чтобы нацелиться на противоположную сторону.<br>
Нагреватель будет потреблять 8 Flux/t на каждую печь, которую ему нужно нагревать. Для предварительного нагрева печи это количество будет увеличено в четыре раза, пока печь не достигнет температуры.<br>
Когда печь при максимальной температуре, Внешний нагреватель будет потреблять в общей сложности §o32 Flux/t§r на печь для увеличенной скорости плавки, если только сигнал редстоуна не отключит ускорение скорости.<br>
Только печи, в которых есть предметы для плавки и место для них, будут нагреваться.
