Машина для розлива
Наполни её!
<&multiblock>Машина для розлива наполняет жидкости в контейнеры или формы.<br>
Структура создаётся как показано выше, но может быть отзеркалена. Чтобы сформировать её, щёлкните правой кнопкой мыши по центральному конвейеру Молотом инженера. Направление конвейеров важно.<np>
Машина может хранить 8 вёдер жидкости, которая вводится через порты на металлическом резервуаре. Энергия вводится через соединение наверху противоположной стороны.<br>
Как правило, Машина для розлива сможет наполнить любой контейнер, у которого есть наполненная версия (ведро, стеклянный пузырёк). Она также примет другие предметы, которые могут хранить жидкости, такие как <link;mining_drill;Шахтёрский Бур;start> или <link;jerrycan;Канистра;start>.<br>
Машина будет держать контейнер, пока он полностью не наполнится, или пока машина не перестанет снабжаться жидкостью.<br>
Это позволяет ей наполнять даже более крупные контейнеры, при условии, что она получает постоянный приток жидкости.<br>
Это поведение можно отключить, присев и щёлкнув по ней правой кнопкой мыши с Молотом инженера.<np>
<&potions>Машину можно использовать для розлива любых зелий, сваренных в <link;mixer;Смесителе>.<br>
Дополнительно, она служит для создания <link;resin_and_duroplast;предметов из дюропласта;duroplast_sheet> из смолы и <link;industrial_fluids;окисления медных блоков;redstone_acid> с помощью редстоуновой кислоты.
