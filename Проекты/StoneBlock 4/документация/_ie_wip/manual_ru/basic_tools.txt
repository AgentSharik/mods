<&engineers_hammer>Молот инженера — один из важнейших инструментов в ящике инструментов инженера.<br>
Его можно использовать для настройки и формирования машин, а также для дробления руд.<np>
<&wirecutters>§lКусачки инженера§r используются для снятия всех проводов, подключённых к блоку, простым щелчком правой кнопкой мыши по нему.<br>
Кусачки также могут снимать провода, протянутые между столбами, при работе с ними.<np>
<&screwdriver>Отвёртка инженера — ещё один распространённый предмет в ящиках с инструментами.<br>
Она используется для точной настройки некоторых видов техники.<np>
<&multimeter>§lВольтметры§r используются для измерения соединений.<br>
Наведя его на любое хранилище энергии или щёлкнув по нему правой кнопкой мыши, можно узнать его текущий уровень.<br>
Щёлкните с приседом правой кнопкой мыши по двум коннекторам, чтобы вычислить средние потери между ними.<br>
Вольтметры также можно использовать для считывания уровня редстоуна блоков, таких как редстоуновые коннекторы и красная пыль.
