# IPN Pick Block Fix для StoneBlock 4

Отдельный клиентский фикс краша **Inventory Profiles Next 2.2.5** на Minecraft **1.21.1 / NeoForge**. В основную сборку и в архив перевода не входит.

## Что произошло в логе

При нажатии средней кнопки мыши (`pickBlock`) IPN вызывает `LockedSlotKeeper.ignoredSelectedHotbarSlot`. В многопользовательской игре этот метод вычисляет слот как `selectedSlot + 36` и читает текущий контейнер без проверки его размера.

В предоставленном crash-report:

- выбранный слот привёл к индексу **38**;
- в текущем контейнере было всего **38 слотов** (допустимые индексы — 0–37);
- возник `IndexOutOfBoundsException: Index 38 out of bounds for length 38`.

Обычное отключение Locked Slots в настройках не является надёжным обходом: IPN ставит флаг `pickingItem` на каждый pick-block отдельно, а проблемный метод не проверяет настройку `ENABLE_LOCK_SLOTS`.

## Что делает фикс

Отключается **только** необязательный вызов `LockedSlotKeeper.ignoredSelectedHotbarSlot(I)V` через клиентский Mixin.

Не изменяются:

- vanilla `pickBlock` и само выделение блока средней кнопкой;
- сортировка, профили, автопополнение и остальные функции IPN;
- libIPN, KubeJS, перевод и файлы других модов;
- серверная часть — устанавливать фикс на сервер не нужно.

Ограничение: специальная логика IPN «проигнорировать hotbar-слот после pick-block» больше не выполняется. Это может влиять только на поведение Locked Slots после такого действия; сам игровой pick-block сохраняется.

## Установка

1. Закрой Minecraft.
2. Оставь `InventoryProfilesNext-neoforge-1.21.1-2.2.5.jar` и `libIPN-neoforge-1.21.1-6.6.3.jar` в клиентской папке `mods`.
3. Скопируй туда же **`IPN-PickBlock-Fix-neoforge-1.21.1-1.0.0.jar`**.
4. Запусти игру, зайди на сервер и проверь среднюю кнопку мыши на блоке. В прежнем случае был выбран третий слот хотбара, дававший индекс 38.

Фикс рассчитан строго на **IPN 2.2.5**. Если автор IPN выпустит подходящее обновление, удалите этот фикс перед проверкой новой версии. Для удаления фикса достаточно убрать его JAR и перезапустить игру.

## Проверка

Выполнено статически:

- ZIP CRC и точный состав JAR;
- воспроизводимая повторная сборка;
- разбор обоих class file двумя независимыми парсерами;
- сигнатура цели — ровно `ignoredSelectedHotbarSlot(I)V`;
- обработчик содержит только `CallbackInfo.cancel()` и `return`;
- проверены Mixin-аннотации, `neoforge.mods.toml` и `ipnpickblockfix.mixins.json`.

**Запуск Minecraft и игровая проверка не выполнялись.** Поэтому результат на сервере нужно подтвердить действием pick-block; при повторной ошибке нужен новый crash-report и `latest.log`.

Воспроизводимая сборка:

```bash
python3 scripts/build_ipn_pick_block_fix.py
python3 scripts/build_ipn_pick_block_fix.py --check
```

Исходники IPN 2.2.5: Codeberg, тег `v2.2.5`, commit `fe9eeb12a714aa30e27e92250dc25a6a51289bde`.
