## Причина английского на скриншотах

Axiom не ограничивается lang-файлом JAR: при смене языка, отличного от английского,
`LocalizationLoader` асинхронно скачивает `translations.zip` с Weblate
(`axiom.moulberry.com/weblate/...`), а при неудаче берёт кэшированный
`translations.zip` из папки конфига и накладывает результат ресурспаком
`Axiom Translations` поверх JAR. Поэтому строки, уже переведённые в JAR
(со скриншота: `axiom.capability.phantom.title` — «Фантом»,
`axiom.capability.phantom.description`, `axiom.block_attributes.title` —
«Редактировать атрибуты блоков»), в игре видны по-английски: их перекрывает
внешняя локализация Weblate, где эти ключи не переведены.

Дополнительно на скриншоте экрана панелей видна зашитая в
`SwitchHotbarScreen` строка `Page \x01` («Page 1») — lang-ключа для неё нет.

## План исправления (по правилам: только доказанные отображаемые литералы)

1. В `LocalizationLoader` точечно отключить внешнюю локализацию для русского:
   замена константы проверки языка `"en"` → `"ru"` только в этом классе —
   скачивание и кэш Weblate для `ru_ru` перестают применяться, источником
   остаётся `ru_ru.json` готового JAR. Остальные языки не затрагиваются.
2. Доперевести доказанные отображаемые литералы `SwitchHotbarScreen`
   (`Page `, обновление, заголовок экрана) через `scripts/patch_axiom_hardcoded.py`.
3. Подписи ImGui переводить партиями по классам после ручной классификации:
   не трогать ID (`##`/`###`), форматы (`%.1f`), шрифты, примеры Lua-кода,
   демо-строки Style Editor и логи/исключения.
4. Пересобрать JAR из исходника: замена только `ru_ru.json` + пропатченные
   классы; сверка содержимого с исходником (отличаются только намеченные записи).

Проверка запуском в игре на стороне сборки не выполнялась: результат
подтверждается проверкой констант внутри готового JAR.
