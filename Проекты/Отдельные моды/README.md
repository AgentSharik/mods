# Отдельные моды

Моды, переведённые **вне сборок**: отдельная просьба, мод из другой сборки или просто мод,
который захотелось перевести. Правила работы и результат те же, что у модов из сборок:
готовый JAR лежит здесь, ход работы — в документации категории.

Документация у каждого проекта своя: журналы и аудиты из папки StoneBlock 4 к этой категории
не относятся. Папка `документация` здесь появится вместе с первым переведённым модом.

Пока категория пустая — раздел заполняется по мере появления модов.
