# Отдельные моды

Сюда попадают моды, переведённые **вне сборок**: отдельная просьба, мод из другой сборки
или просто мод, который захотелось перевести. Правила работы и результат те же, что и для модов
из сборок: готовый JAR лежит рядом, ход работы — в журнале.

Пока категория пустая — раздел заполняется по мере появления модов.
