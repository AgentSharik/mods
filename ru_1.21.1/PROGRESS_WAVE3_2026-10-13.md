## 3. OmniTools `omnitools-1.2.2.jar` — 32 ключа, перевод с нуля

**Аудит.** 153 записи, один lang-файл `assets/omnitools/lang/en_us.json` (32 ключа),
`ru_ru` нет, есть только `ja_jp` и `zh_cn`. Книг и гайдов нет. По классам видно, что мод —
это «один ключ вместо многих»: обработчики совместимости есть для AE2, Mekanism, Create,
Powah, Industrial Foregoing, Entangled, Draconic Evolution, Logistics Networks,
Immersive Engineering, ExtendedAE и ME Beam Former.

**Сверка источника.** Публичного репозитория мода не найдено (`Galissudo/OmniTools`,
`TeamGalissudo/OmniTools` — 404). Источник перевода — `en_us.json` из JAR; состав ключей
проверен по классам `com/omnitools/omniTools/compat/*`: список модов из `omnitools.compat.*`
совпадает с пакетами совместимости один в один.

**Перевод с нуля.** Все 32 ключа переведены, из них 8 — это названия модов-совместимости
(`[OmniTools] Applied Energistics 2`, `[OmniTools] Mekanism` и так далее) и одно название
творческой вкладки (`OmniTools`); они оставлены в оригинале по правилу о брендах.
Итого переведено **23 строки**, 9 оставлено как есть.

**Решения по терминологии:**

| Оригинал | Перевод | Обоснование |
|---|---|---|
| Omni Wrench | Омни-гаечный ключ | wrench по каталогу = «гаечный ключ» (Mekanism `alias.mekanism.tool.wrench`) |
| Omni Vajra | Омни-ваджра | ваджра — устоявшаяся русская транслитерация санскритского слова; буквального перевода нет |
| Wrench Mode | Режим ключа | короткая форма для режима инструмента |
| Link Mode[no wrech tag] | Режим привязки [нет тега ключа] | в оригинале опечатка `wrech` вместо `wrench`; переведено по смыслу |
| Rename Mode[quartz_cutting_knife] | Режим переименования [quartz_cutting_knife] | в скобках — часть идентификатора предмета AE2, оставлен как технический |
| Silk Touch | Шёлковое касание | сверено с ванильным ru_ru 1.21.1 |
| On / Off | Вкл. / Выкл. | по каталогу: Mekanism `boolean.mekanism.on` = «Вкл.»; ваниль даёт форму без точки, сознательно взята форма каталога |
| Gameplay | Игровой процесс | сверено с ванильным ru_ru 1.21.1 |
| Auto Pickup | Автоматический подбор | подбор добычи в инвентарь |
| Cleared stored logistics node settings | Сохранённые настройки логистического узла очищены | режим буфера обмена для Logistics Networks |

**Вычитка.** Второе чтение русского текста отдельно от английского: все 23 строки читаются
как нормальный русский интерфейс, кавычки «ёлочкой» только там, где это название
зачарования («Шёлковое касание»). Перекрёстная сверка `en_us` ↔ `ru_ru` по парам —
пропусков и вставок нет.

**Спорные места:**

1. **«Омни-гаечный ключ»** — длиннее оригинала, зато исключает двусмысленность: «ключ»
   по-русски и ключ-инструмент, и ключ от двери. Если нужен короткий вариант — «Омни-ключ».
2. **«Омни-ваджра»** — транслитерация. Смыслового перевода («молния», «алмаз») не предлагается:
   это имя собственное предмета.
3. **`[no wrech tag]`** — опечатка в оригинале сохранена в смысле, но не в написании:
   переведено как «[нет тега ключа]». Если автор исправит опечатку, строку надо пересмотреть.

**Техпроверка скриптом** (`work/build_lang.py`): ключей 32/32, пропущенных и лишних нет,
плейсхолдеры `%s` и `§`-коды совпадают во всех строках, JSON валиден, `testzip` чистый.
В архиве 154 записи (153 исходных + новый `ru_ru.json` на месте своего отсутствия —
в конец архива), размер 144 447 б,
SHA-256 `fc48494a1f48c586f4f1818bf297d5f229f804631bea92f28cc86aa9d06b4745`.
