## Что намеренно осталось латиницей

**25 строк из 2046** — это не недоработка, переводить их нельзя:

| Что | Примеры |
|---|---|
| Единицы и физические обозначения | `RF`, `CF`, `FE`, `FOV`, `I/O` |
| Оси координат | `X:`, `Y:`, `Z:`, `X: %s` |
| Бренды и имена модов | `Emotecraft`, `BuildingGadgets2`, `3spooky5me` |
| Идентификаторы рецептов | `forge:experience` |
| Форматные шаблоны ICU | `{0,choice,0#condition|1<conditions>}` |
| Чистые плейсхолдеры | `%s`, `{0}s`, `+%d`, `[%s] +` |
| Форматирование | `§o???`, `§7- `, `§4✕ `, `§a✔ ` |

## Технические детали

* Идентификаторы ресурсов не менялись: `icon:`, `id=`, `location=`, `parent:`,
  `item_ids:`, `slots={...}` в документации не тронуты.
* В документации не переводятся блоки кода, ссылки и YAML-ключи —
  переводятся только прозаические строки.
* Структурных проблем в сборке нет (`verify_mp.py`: 0).
* Уже переведённые моды не трогались: в партию попали только те, где русского не было.
* Сквозная проверка на воркспейсе и в git.
