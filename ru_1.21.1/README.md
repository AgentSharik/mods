# Русификация модов Minecraft 1.21.1 — NeoForge

Здесь собраны русифицированные JAR-файлы модов и заметки о покрытии локализации. Версии файлов подобраны для Minecraft **1.21.1**; копируйте в `mods` только те моды, которые уже есть в вашей сборке.

> **Установка:** замените оригинальный JAR соответствующим файлом из `ru_1.21.1/`. Не кладите оригинал и русифицированную копию рядом — игра может загрузить обе версии. Перед заменой сохраните резервную копию сборки.

## Правила локализации и проверка

- Ключи языковых файлов и пути ресурсов не переименовывались. Для 15 модов с исходным JAR в репозитории проверено полное покрытие исходных `en_us`-ключей; для ещё семи коротких модов покрытие сверено по upstream-файлам `en_us.json`. Для Patchouli сверены 92/92 ключа с точным тегом `release-1.21.1-93`, для Particular — 111/111 ключей с исходным файлом версии 1.5.7 (коммит `b4f92d4`), для Oritech Things — 138/138 ключей с точным тегом `v0.0.46` (коммит `7b0f274`), для Mekanism: Ponders — 150/150 с языковым файлом из коммита версии 1.0.3 (`5e45f05`), для Apothic Attributes — 161/161 с исходным JAR 2.10.1; 111 дополнительных legacy-ключей сверены с AttributesLib `1.20` (коммит `efe1efb`), для Ars Affinity — 162/162 с исходным JAR версии 1.1.1, для Simply Light — 192/192 с английским файлом из upstream-тега `v1.5.3` (сверенным с веткой `1.21.1-multi`). Для Simple Tomb найден только более старый upstream `en_us.json` (`trunk/1.20`): сверены 50 общих ключей, а 34 дополнительных ключа версии 1.4.4 требуют точного английского источника. Остальным модам также нужен оригинал точной версии — подробности в [аудите](AUDIT_2026-10-07.md).
- В переведённых JAR `en_us.json` синхронизирован с русским как резервный язык; остальные языковые JSON в этих каталогах удалены.
- Плейсхолдеры (`%s`, `%1$d`, `%%`), форматирование `§`, Patchouli-макросы и фрагменты в квадратных скобках сохраняются. Названия кнопок и клавиш (например, `Shift` и `Ctrl`), названия модов, музыкальные произведения и технические идентификаторы не переводятся без необходимости; поясняющий текст вокруг названия клавиши переводится.
- Исходные JAR-файлы в корне репозитория не изменяются. Новые архивы проверены на целостность ZIP, корректность JSON и совпадение плейсхолдеров, форматирования и разметки.

Каталог содержит **34 JAR-файла**. Точное соответствие версии мода важно: русифицированная копия предназначена для той версии, что указана в имени файла.
