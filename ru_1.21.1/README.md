# Русификация модов Minecraft 1.21.1 — NeoForge

Здесь собраны русифицированные JAR-файлы модов и заметки о покрытии локализации. Версии файлов подобраны для Minecraft **1.21.1**; копируйте в `mods` только те моды, которые уже есть в вашей сборке.

> **Установка:** замените оригинальный JAR соответствующим файлом из `ru_1.21.1/`. Не кладите оригинал и русифицированную копию рядом — игра может загрузить обе версии. Перед заменой сохраните резервную копию сборки.

### Simply Swords — вычитка версии 1.70.2-1.21.1

Русская локализация `simplyswords-neoforge-1.70.2-1.21.1.jar` сверена с точным upstream-коммитом `Sweenus/SimplySwords` [`359a8031b1a3243d1a3b013dbaa0cbba70ea8278`](https://github.com/Sweenus/SimplySwords/commit/359a8031b1a3243d1a3b013dbaa0cbba70ea8278). Проверены все 2 267 языковых ключей, включая 278 текстовых ключей подсказок предметов, четыре вспомогательных значка и 23 описания способностей; пустое значение сохранено, ключи и плейсхолдеры совпадают с источником. Уточнены десять связанных подписей и описаний настроек о способностях существ, не являющихся игроками, и призванных прислужниках. Полностью сверены 146/146 встроенных MDX и 7/7 файлов `_meta.json`; 90 страниц и четыре набора подписей навигации вычитаны прямо по существующим путям внутри JAR, без второго локализованного каталога. Сохранены структура, идентификаторы, ссылки и компоненты Oracle Index. Механики «Бури» (Tempest) и Искривлённого клинка сверены с кодом; для Охотника за душами сохранены езда верхом на шестиконечном стигийском скакуне и зарядка направленного прыжка согласно русской подсказке предмета. Подробности и статические проверки — в [аудите Simply Swords](AUDIT_2026-10-07.md).
