# Русификация модов Minecraft 1.21.1 — NeoForge

Здесь собраны русифицированные JAR-файлы модов и заметки о покрытии локализации. Версии файлов подобраны для Minecraft **1.21.1**; копируйте в `mods` только те моды, которые уже есть в вашей сборке.

> **Установка:** замените оригинальный JAR соответствующим файлом из `ru_1.21.1/`. Не кладите оригинал и русифицированную копию рядом — игра может загрузить обе версии. Перед заменой сохраните резервную копию сборки.

## Правила локализации и проверка

- Ключи языковых файлов и пути ресурсов не переименовывались; `ru_ru.json` содержит полный набор исходных ключей.
- В переведённых JAR `en_us.json` синхронизирован с русским как резервный язык; остальные языковые JSON в этих каталогах удалены.
- Плейсхолдеры (`%s`, `%1$d`, `%%`), форматирование `§`, Patchouli-макросы и фрагменты в квадратных скобках сохраняются. Надписи кнопок, `shift`, `hold`, `press`, названия модов, музыкальные произведения и технические идентификаторы не переводятся без необходимости.
- Исходные JAR-файлы в корне репозитория не изменяются. Новые архивы проверены на целостность ZIP, корректность JSON и совпадение плейсхолдеров, форматирования и разметки.

Каталог содержит **34 JAR-файла**. Точное соответствие версии мода важно: русифицированная копия предназначена для той версии, что указана в имени файла.
