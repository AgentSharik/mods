## 5. Правила, действующие без изменений

- Естественный русский, обращение на «вы», последовательная терминология; для Malum — вести глоссарий и сверять с ним каждую запись книги.
- Ключи, плейсхолдеры, форматирование, ссылки, ассеты и структура файлов не меняются.
- `Shift`, `hold`/`Hold`, `press`/`Press`, технические единицы, текст в квадратных скобках и подписи кнопок остаются в оригинале.
- `right-click` → «нажмите ПКМ», `shift-right-click` → «нажмите ПКМ, удерживая Shift».
- Названия модов, музыкальные произведения и технические идентификаторы — без перевода.
- Пустые значения не заполняются догадками; массовые автоподстановки не применяются.
- Мод не считается вычитанным, пока проверка не закончена. Игра не запускается, поэтому экранная вычитка GUI/HUD/книг не выполняется — это фиксируется в журнале.

### Обязательный проход вычитки после перевода

Перевод без самопроверки в работу не идёт. Для каждого мода последовательно:

1. **Перевод** — черновой проход по всем ключам и файлам книги.
2. **Вычитка перевода** — второе, медленное чтение уже готового русского текста отдельно от английского: проверяются естественность, обращение на «вы», единообразие терминов по глоссарию, отсутствие канцелярита и калек. Всё подозрительное правится сразу.
3. **Сверка с оригиналом** — выборочный и, для книг, сплошной перекрёстный просмотр `en_us` ↔ `ru_ru`: не потеряны ли смысл, детали, числа и оговорки; там, где русский текст заметно короче или длиннее английского, проверяется каждый такой ключ.
4. **Техническая проверка** — ZIP/CRC, все JSON строгим парсером, плейсхолдеры, `§`-коды, переносы, краевые пробелы, макросы и ссылки книги, ключи один в один с `en_us`.
5. **Публикация** — коммит, пуш, проверка, что удалённая ветка содержит нужный коммит.

Результат вычитки фиксируется в журнале: сколько ключей проверено, что исправлено, что осталось намеренно по-английски.

## 6. Решения, принятые 10.10.2026

1. **Malum переводится с нуля.** От старого файла берём только то, что точно полезно и правильно, — в первую очередь терминологию (духосталь, Опека Души, Рунное дерево, Ритуал Духа, тигель духа). Восемь ключей `malum.spirit.flavour.*` переводим, решение предыдущего переводчика оставить их по-английски не сохраняем. Старый файл остаётся в истории как справочник, в собираемый JAR не попадает.
2. **Вика Oracle Index переводится целиком**, включая раздел `developer` (setup, gradle-таск, синтаксис markdown, разблокировка контента).
3. **Состав исходников в ветке.** Всё, что лежало до второй волны, остаётся. Копии **Malum и Cataclysm из сборки удалены** — вместо них в ветке лежат **оригиналы с CurseForge**:
   ```
   malum-1.21.1-1.8.2 curseforge.jar                 32 МБ
   L_Ender's Cataclysm 1.21.1-3.33 curseforge.jar    70 МБ
   ```
   Malum совпадает с файлом из сборки побайтово, поэтому git оформил замену как чистое переименование. У Cataclysm содержимое отличается одной строкой лицензии, и она остаётся как в оригинале: `LGPL v3.0` вместо `CC BY-NC-ND 4.0`.
   Текущие размеры: корень — 246 МБ (51 JAR), переведённые JAR в `ru_1.21.1/` — 98 МБ, `.git` — 422 МБ. Места на диске достаточно (свободно 19 ГБ).

### Таблица 3. Правила перевода

| Элемент | Как переводим | Пример |
|---|---|---|
| `right-click` | нажмите ПКМ | «нажмите ПКМ по блоку» |
| `shift-right-click` | нажмите ПКМ, удерживая Shift | — |
| `Shift`, `Hold`, `Press` | технические слова остаются | `Hold [ALT]` → «Удерживайте [ALT]» |
| Единицы: RF, RF/t, mB/t, FE, L | без перевода | «100 RF/t» |
| `%s`, `%1$s`, `%d` | переносятся без изменений, в том же порядке | — |
| `§`-коды, `\n`, `$i…/$` | сохраняются как есть | — |
| Названия модов, бренды, музыкальные треки | без перевода | `Yuri_O - Spawn Of Hell` |
| Имена собственные в игре | по-русски, единообразно | `Netherite Monstrosity` → «Незеритовое чудище» |
| Пустые значения | не заполняются догадками | `entity.cataclysm.rage_meter` |
| Обращение к игроку | на «вы» | «Если вы нажмёте…» |
| Книги | проза, живой язык, без канцелярита | книга Malum — от первого лица |

### Таблица 4. Что именно проверяет вычитка

| Проверка | Что ищем |
|---|---|
| Смысл | Потерянные детали, числа, оговорки, перевёрнутый смысл |
| Длина | Русский заметно короче или длиннее английского — перепроверить каждый такой ключ |
| Термины | Один английский термин — один русский; сверка с глоссарием мода |
| Обращение | «вы», а не «ты»; единообразно в пределах мода |
| Естественность | Кальки с английского, канцелярит, несогласованные падежи |
| Форматирование | Плейсхолдеры, `§`-коды, переносы, краевые пробелы, ссылки, макросы |
| Регистр | Названия записей и заголовки — единообразно |
| Намеренный английский | Только там, где того требует источник: названия модов, треки, идентификаторы |
