# Fallen Relics

Автоупаковщик для Minecraft 1.21.1 и NeoForge 21.1.250. Это отдельный аддон: он не изменяет и не заменяет JAR Functional Storage. Предметы можно подавать и извлекать трубами через любую сторону блока.

## Возможности

- Использует переданные текстуры Auto-Packager.
- Поддерживает режимы оригинального Auto-Packager: 2×2 с переходом на 3×3, 3×3 с переходом на 2×2, только 2×2, только 3×3, полая 3×3 и только 1×1.
- Перебирает зарегистрированные рецепты верстака через менеджер рецептов Minecraft, включая рецепты установленных модов. Поддерживаются обычные shaped- и shapeless-рецепты; для специальных рецептов используются опубликованные ими ингредиенты.
- Полая 3×3 оставляет центральную ячейку пустой. Режимы выбираются пустой рукой: Shift + ПКМ переключает режим, обычный ПКМ показывает текущий.
- Не требует и не расходует энергию.
- Трубы могут использовать любой бок блока: входные слоты доступны для вставки, выходные — для извлечения. Одна и та же сторона поддерживает и ввод, и вывод.

## Рецепт

```text
Железо     | Поршень | Железо
Поршень    | Сборщик | Поршень
Железо     | Редстоун| Железо
```

В центре используется ванильный `minecraft:crafter`; золотая катушка заменена редстоуном.

## Установка

1. Нужны Minecraft 1.21.1 и NeoForge 21.1.250 или новее в ветке 21.1.
2. Поместите `fallen-relics-neoforge-1.21.1-1.0.2.jar` в папку `mods` вместе с Functional Storage и любыми трубами для предметов.

Functional Storage указан как необязательная зависимость; его код и JAR не включены в аддон.

## Сборка

Для ручной сборки нужен Java 21: `./gradlew build`. GitHub Actions собирает JAR при изменениях проекта, публикует его в корне ветки сессии и прикладывает к запуску workflow как артефакт.
