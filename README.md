## Что здесь

- **В папке «Проекты»** лежат готовые переведённые JAR: моды из сборок и отдельные моды вне сборок.
- **Сборки целиком** выкладываются в раздел [Releases](https://github.com/AgentSharik/mods/releases) одним архивом — сейчас там StoneBlock 4.
- **В папке «Исходные моды для перевода»** — нетронутые оригинальные JAR. По ним видно, с какой именно версии мода сделан перевод.
- **Документация** каждого проекта лежит в подпапке `документация` рядом с его модами.

## Структура репозитория

```
mods/
├── Проекты/
│   ├── StoneBlock 4/              моды сборки StoneBlock 4 и её документация
│   └── Отдельные моды/            моды вне сборок
├── Исходные моды для перевода/    оригиналы, не изменяются
├── scripts/                       служебные скрипты (патчеры, пересчёт счётчиков)
└── README.md
```

## Как пользоваться отдельным модом

1. Возьмите из папки проекта JAR с тем же именем, что у установленного мода.
2. Замените им файл в папке `mods` своей сборки (резервную копию держать стоит).
3. В игре выберите русский язык — перевод лежит внутри мода файлом `ru_ru.json`.

Рядом оригинал и переведённую копию класть нельзя: игра загрузит обе версии мода. После обновления мода перевод нужно ставить заново поверх новой версии.

## Правила перевода

- Перевод — литературный, а не подстрочник: текст вычитывается глазами обычного русского читателя.
- Имена собственные — аккуратной транслитерацией, прозвища и титулы — по смыслу.
- Чужой готовый перевод не заменяется своим: если у проекта есть перевод владельца, он идёт в релиз как есть и только дополняется недостающим.
- Числа в этом README не пишутся вручную: их пересчитывает `scripts/update_readme_stats.py` по фактическому содержимому JAR, а workflow `README stats check` следит, чтобы цифры не расходились с фактом.
