# Fallen Relics

Отдельный NeoForge-аддон для Minecraft 1.21.1 (целевая версия NeoForge — 21.1.250). Внутренний mod ID: `fallenrelics`. По легенде, потерянные реликвии древности вновь обрели силу — одна из них автоматически упаковывает предметы по рецептам верстака. Аддон не изменяет и не заменяет JAR Functional Storage.

## Возможности

- Автоматически использует зарегистрированные рецепты верстака Minecraft и установленных модов.
- Не требует и не расходует энергию.
- Предметы можно подавать во входные слоты и извлекать результат через трубы с любой стороны блока.
- Сохраняет режимы 2×2/3×3, только 2×2, только 3×3, полую 3×3 (восемь ингредиентов на результат) и 1×1. Shift + ПКМ пустой рукой меняет режим.
- Четыре предмета-улучшения устанавливаются ПКМ по упаковщику и меняют сетку на его лицевой стороне. В каждом цикле обработки упаковщик выполняет до 2, 4, 8 или 16 крафтов соответственно железному, золотому, алмазному и незеритовому улучшению.
- При разрушении упаковщика установленное улучшение и содержимое выпадают.
- Интерфейс переведён на русский язык; GUI для улучшений не добавляется.

## Рецепты

Упаковщик: железо в углах, поршни по сторонам, ванильный Crafter в центре и редстоун снизу по центру.

Шаблон улучшения:

```text
Камень   | Редстоун | Камень
Редстоун | Кирпич   | Редстоун
Камень   | Редстоун | Камень
```

В центре используется предмет кирпича `minecraft:brick`.

Каждое улучшение изготавливается по одной схеме: соответствующий материал в четырёх углах, редстоун в четырёх боковых ячейках и предыдущее улучшение в центре. Для железного улучшения в центре используется шаблон; для золотого, алмазного и незеритового — предыдущее улучшение по цепочке.

| Улучшение | Материал в углах | Предмет в центре | Крафтов за цикл |
| --- | --- | --- | ---: |
| Железное | Железный слиток | Шаблон улучшения | 2 |
| Золотое | Золотой слиток | Железное улучшение | 4 |
| Алмазное | Алмаз | Золотое улучшение | 8 |
| Незеритовое | Незеритовый слиток | Алмазное улучшение | 16 |

## Установка

1. Нужны Minecraft 1.21.1 и NeoForge 21.1.250 или новее в ветке 21.1.
2. Поместите `fallen-relics-neoforge-1.21.1-1.1.0.jar` в папку `mods` вместе с Functional Storage и любыми трубами для предметов.

Functional Storage указан как необязательная зависимость; его код и JAR не включены в аддон.

## Сборка

Для ручной сборки нужен Java 21: `./gradlew build`. GitHub Actions собирает JAR при изменениях проекта и прикладывает его к запуску workflow как артефакт.
