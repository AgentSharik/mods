# Fallen Relics

**Fallen Relics** — самостоятельный NeoForge-мод для Minecraft 1.21.1 (целевая версия NeoForge — 21.1.250). Внутренний mod ID: `fallenrelics`. По легенде, потерянные реликвии древности вновь обрели силу.

## Возможности

- **Автоупаковщик** — автоматический крафтер, который выполняет рецепты из предметов, поданных в его слоты. Он не сжимает предметы в коробки или блоки.
- Не требует и не расходует энергию. Предметы можно подавать и извлекать через совместимые трубы с любой стороны.
- Режимы автоупаковщика: гибридные 2×2/3×3, только 2×2, только 3×3, полая 3×3 (8 ингредиентов на результат) и 1×1. Shift + ПКМ пустой рукой переключает режим.
- Четыре улучшения меняют лицевую сетку автоупаковщика и повышают число крафтов за цикл: железное — 2, золотое — 4, алмазное — 8, незеритовое — 16.
- Блок **Крафтбилдер** открывает редактор рецептов 3×3. Выложите ингредиенты и результат, выберите шаблонный или бесформенный режим и нажмите «Добавить»; кнопка «Удалить» удаляет рецепт.
- **Карманный Крафтбилдер** создаётся из блока Крафтбилдера над палкой. ПКМ открывает тот же редактор, а сетка и режим хранятся в самом предмете.
- Рецепты Крафтбилдера хранятся в собственных файлах `.frs` в `scripts/fallenrelics/` на сервере. Они загружаются при входе в мир; изменения можно применить без перезапуска.
- Команда `/fallenrelics reload` перечитывает `.frs` (уровень прав 2). Сервер обновляет рецепты у подключённых игроков.
- Старые пользовательские рецепты, созданные предыдущими сборками Крафтбилдера, переносятся в `.frs`. Постоянным источником остаются скрипты, а не JSON-рецепты в папке мира.
- При разрушении автоупаковщика или Крафтбилдера их содержимое выпадает; установленное улучшение автоупаковщика также сохраняется.

## Модели и текстуры

- Блок Крафтбилдера — объёмная модель куба с отдельными текстурами лицевой, боковых и верхней граней.
- Карманный Крафтбилдер и улучшения имеют объёмные пиксельные модели. Прозрачные области текстур образуют вырезы, а видимая форма имеет толщину.
- Установленный тир улучшения отображается на лицевой стороне автоупаковщика.

## Формат скриптов `.frs`

Один файл задаёт один рецепт. Имя файла становится ID рецепта. Для шаблонного рецепта используются три строки по три ячейки; `_` означает пустую ячейку:

```text
# Fallen Relics standalone recipe script v1
type shaped
result minecraft:diamond 1
grid
minecraft:diamond_block _ minecraft:diamond_block
_ minecraft:stick _
_ _ _
```

Для бесформенного рецепта перечислите ингредиенты построчно:

```text
# Fallen Relics standalone recipe script v1
type shapeless
result minecraft:diamond 1
ingredients
minecraft:diamond_block
minecraft:stick
```

Файлы `.frs` — постоянный источник пользовательских рецептов. Сервер компилирует их в памяти и обновляет карты рецептов напрямую, без полной перезагрузки ресурсов; изменения из редактора сразу синхронизируются подключённым игрокам. После ручного редактирования файла выполните `/fallenrelics reload`.

## Рецепты автоупаковщика и улучшений

Автоупаковщик: железо в углах, поршни по сторонам, Crafter в центре и редстоун снизу по центру.

Рецепт шаблона улучшения:

```text
Камень   | Редстоун | Камень
Редстоун | Кирпич   | Редстоун
Камень   | Редстоун | Камень
```

В центре используется предмет кирпича `minecraft:brick`. Каждое улучшение изготавливается по одной схеме: соответствующий материал в четырёх углах, редстоун в боковых ячейках и предыдущее улучшение в центре. Для железного улучшения в центре используется шаблон.

| Улучшение | Материал в углах | Предмет в центре | Крафтов за цикл |
| --- | --- | --- | ---: |
| Железное | Железный слиток | Шаблон улучшения | 2 |
| Золотое | Золотой слиток | Железное улучшение | 4 |
| Алмазное | Алмаз | Золотое улучшение | 8 |
| Незеритовое | Незеритовый слиток | Алмазное улучшение | 16 |

Крафтбилдер: алмазные блоки в углах, редстоун-блоки сверху и снизу по центру, верстак слева, печь справа и алмазное улучшение автоупаковщика в центре.

## Установка и сборка

- Нужны Minecraft 1.21.1 и NeoForge 21.1.250 или новее в ветке 21.1.
- Для сетевой игры установите Fallen Relics на сервере и на клиентах.
- Для ручной сборки нужен Java 21: `./gradlew build`. GitHub Actions собирает JAR при изменениях проекта и прикладывает его к запуску workflow как артефакт.
