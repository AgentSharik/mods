# Fallen Relics

Самостоятельный NeoForge-мод для Minecraft 1.21.1 (целевая версия NeoForge — 21.1.250). Внутренний mod ID: `fallenrelics`. По легенде, потерянные реликвии древности вновь обрели силу. Это не AutoPackager и не замена Functional Storage; его JAR мод не изменяет.

## Возможности

- Основная машина — **Упаковщик реликвий**, автоматический крафтер по стандартным рецептам верстака Minecraft и установленных модов. Он выполняет рецепты из поданных предметов; это не упаковщик, который сжимает предметы в коробки или блоки.
- Не требует и не расходует энергию.
- Предметы можно подавать во входные слоты и извлекать результат через трубы с любой стороны упаковщика.
- Сохраняет режимы 2×2/3×3, только 2×2, только 3×3, полую 3×3 (восемь ингредиентов на результат) и 1×1. Shift + ПКМ пустой рукой меняет режим упаковщика.
- Четыре предмета-улучшения меняют лицевую сетку упаковщика и дают до 2, 4, 8 или 16 крафтов за цикл.
- Блок **Крафтбилдер** открывает редактор 3×3: выложите ингредиенты и предмет-результат, переключите шаблонный/бесформенный рецепт, затем нажмите «Добавить». Рецепты можно удалить кнопкой «Удалить».
- **Карманный Крафтбилдер** получается из блока Крафтбилдера и палки. ПКМ открывает тот же редактор со всеми функциями блока; сетка и режим сохраняются прямо в предмете.
- Fallen Relics автономен: CraftTweaker или другая скриптовая модификация не требуются. Источник рецептов — собственные файлы `.frs` в `scripts/fallenrelics/` в каталоге сервера. После добавления или удаления рецепта Крафтбилдер компилирует скрипты, перезагружает рецепты и рассылает обновление подключённым игрокам без перезапуска.
- Администратор может править `.frs` вручную и применить изменения командой `/fallenrelics reload` (требуется уровень прав 2). Рецепты доступны обычному верстаку и упаковщику.
- Сценарии `.zs`, сгенерированные прежней версией, и старые пользовательские JSON-рецепты автоматически переносятся в `.frs` при запуске сервера. Постоянным источником остаются скрипты; JSON в папку мира не сохраняются.
- При разрушении упаковщика или Крафтбилдера их содержимое выпадает; установленное улучшение упаковщика также выпадает.
- Интерфейс переведён на русский язык. Для улучшений упаковщика GUI нет; отдельный GUI есть у блока и карманного Крафтбилдера.

## Модели и текстуры

- Блок Крафтбилдера — полноценная 3D-модель куба с отдельными текстурами лицевой, боковых и верхней граней; его предмет в инвентаре использует ту же объёмную модель.
- Карманный Крафтбилдер и предметы улучшений представлены объёмными пиксельными моделями, а не плоскими прямоугольными спрайтами. Прозрачные участки исходных текстур остаются вырезами, а видимая пиксельная форма имеет толщину.
- Установленный тир улучшения также виден на лицевой стороне Упаковщика реликвий.

В редакторе ингредиенты сопоставляются по типу предмета; порядок слотов учитывается в шаблонном режиме и игнорируется в бесформенном. Результат сохраняет количество предметов из слота результата.

## Формат автономного скрипта

Один файл `.frs` задаёт один рецепт. Для шаблонного рецепта используйте три строки сетки по три ячейки; `_` означает пустую ячейку:

```text
# Fallen Relics standalone recipe script v1
type shaped
result minecraft:diamond 1
grid
minecraft:diamond_block _ minecraft:diamond_block
_ minecraft:stick _
_ _ _
```

Для бесформенного рецепта укажите ингредиенты построчно:

```text
# Fallen Relics standalone recipe script v1
type shapeless
result minecraft:diamond 1
ingredients
minecraft:diamond_block
minecraft:stick
```

Скрипты, созданные редактором, компилируются Fallen Relics во временные определения рецептов Minecraft и синхронизируются штатным способом. Это служебный runtime-кэш, а не сохраняемые datapack-рецепты.

## Рецепты блоков и улучшений

Упаковщик: железо в углах, поршни по сторонам, ванильный Crafter в центре и редстоун снизу по центру.

Шаблон улучшения:

```text
Камень   | Редстоун | Камень
Редстоун | Кирпич   | Редстоун
Камень   | Редстоун | Камень
```

В центре используется предмет кирпича `minecraft:brick`.

Каждое улучшение изготавливается по одной схеме: соответствующий материал в четырёх углах, редстоун в боковых ячейках и предыдущее улучшение в центре. Для железного улучшения в центре используется шаблон.

| Улучшение | Материал в углах | Предмет в центре | Крафтов за цикл |
| --- | --- | --- | ---: |
| Железное | Железный слиток | Шаблон улучшения | 2 |
| Золотое | Золотой слиток | Железное улучшение | 4 |
| Алмазное | Алмаз | Золотое улучшение | 8 |
| Незеритовое | Незеритовый слиток | Алмазное улучшение | 16 |

Крафтбилдер: алмазные блоки в углах, редстоун-блоки сверху и снизу по центру, верстак слева, печь справа и алмазное улучшение упаковщика в центре.

Карманный Крафтбилдер: блок Крафтбилдера над палкой. Использование предмета ПКМ открывает тот же редактор; сетка и выбранный тип рецепта сохраняются в данных предмета.

## Установка

1. Нужны Minecraft 1.21.1 и NeoForge 21.1.250 или новее в ветке 21.1.
2. Поместите `fallen-relics-neoforge-1.21.1-1.3.1.jar` в папку `mods` вместе с Functional Storage и любыми трубами для предметов. На клиентах тоже должен быть Fallen Relics; CraftTweaker ставить не нужно.

Functional Storage указан как необязательная зависимость; его код и JAR не включены в мод.

## Сборка

Для ручной сборки нужен Java 21: `./gradlew build`. GitHub Actions собирает JAR при изменениях проекта и прикладывает его к запуску workflow как артефакт.
